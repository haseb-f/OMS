# تسليم الجولة 22 — المقبوضات والمدفوعات وتسوية الفواتير

**الحالة:** منشورة على الإنتاج (`8ac30bfa`، نشر Vercel ناجح، 2026-10-14).

**الأسباب الجذرية**

- حالة الفاتورة كانت تتجاهل المرتجعات/الإشعارات الدائنة → فاتورة مُسوّاة تظهر مفتوحة وتقبل تحصيلاً ثانياً.
- فرق العملة يُقيَّد فقط عند التأكيد لا عند التخصيص اللاحق أو إلغائه، والقيود تؤرَّخ بيوم التأكيد لا بتاريخ السند.
- أعمار الديون تجمع عملات مختلفة، وتُخفي فاتورة مؤرشفة لها رصيد.
- حواجز ناقصة: سباق التخصيص مع الإلغاء، تحصيلات الوكلاء تسدد فواتير، تخصيص بين شركات، رسوم بلا حد، تعديل التخصيص بخطوتين غير ذريتين.
- الواجهة: حقل مبلغ عام (type=number يرفض الأرقام العربية ويحوّل «0.5»)، أعمدة المدفوع/المتبقي مخفية، أعمدة رقمية معكوسة في RTL، ترتيب بالعميل يعطي 500، سجل تسوية غير موجود، ولا تحديث بعد العمليات.
- عمليات ناقصة: تحصيل/صرف آخر بحساب مقابل، تحويل بين الحسابات، رد دفعة مقدمة.

**الإصلاحات**

- مصدر واحد للتسوية: الإجمالي، المدفوع نقداً، الإشعارات الدائنة منفصلة، المتبقي، الحالة (غير مدفوعة / مدفوعة جزئياً / مدفوعة بالكامل / مسوّاة / ملغاة).
- قيود على تاريخ السند، فرق عملة عند التخصيص وعكسه عند الإلغاء، سجل تخصيص غير قابل للتعديل لأعمار الديون، أعمار ديون لكل عملة.
- أنواع سندات جديدة: تحصيل آخر، صرف آخر، تحويل بين الحسابات، رد دفعة مقدمة — قيود متوازنة عند التأكيد فقط، والتحويل بلا إيراد/مصروف.
- بطاقة سند واحدة تدريجية: الغرض ← الطرف/الحساب ← «المبلغ المقبوض/المدفوع» بارز بعملته وفارغ مع «أدخل المبلغ» ← الفواتير ← مراجعة قبل التأكيد.
- قوائم الفواتير تعرض الإجمالي/المدفوع/المتبقي/الحالة، وتفاصيل الفاتورة تعرض «حالة السداد» وسجل التسوية، ومحاذاة رقمية صحيحة، وتحديث تلقائي بعد كل عملية، وقوائم للسندات الجديدة.
- بعد المراجعة المستقلة: التأكيد يحتاج صلاحية «ترحيل» والإلغاء «عكس» (فصل المهام)، والحساب المقابل يستبعد حسابات الوحدات الأخرى ودفاتر الشركاء.

**السجلات المصححة:** لا يوجد قيد أو حالة خاطئة على الإنتاج، فلم يُعدَّل أي سجل. بانتظار قرارك: CR-2026-000101 (20,000) وCR-2026-000103 (60,000) لمكتبة النور غير مخصصين بينما INV-2026-000093 عليها 60,000.

**الأدلة:** API ‏2,761/2,763 (فشل بيئي معروف) + تسلسلي 238/238، الويب 1,432/1,432، 16 رحلة محاسبية 382/382 فحص، متصفح محلي 30/30، تحقق حي على الإنتاج 25/25 + 19/19، مراجعة محاسبية مستقلة «معتمدة».

**القيود المتبقية:** مطابقة سطر بنكي مستورد بسند تحويل مسجّل غير متاحة بعد؛ رد المورد خارج النطاق؛ قائمة الحسابات المقابلة صارمة (3 حسابات على الإنتاج) ويمكنك توسيعها؛ قيود قديمة مرحّلة بتاريخ التأكيد تُقرأ بتاريخ السند في أعمار الديون التاريخية (أثر منخفض).
