# Route Inventory — enterprise-ui-overhaul

Generated 2026-09-27 by INV-ROUTES from `apps/web/src/app/**/page.tsx` (175 routes). Route groups `(shell)` are stripped from paths; `(auth)` and `investor/(app|public)` are kept because they use separate layouts.

## Method & legend

- Each page was scanned together with every file it imports transitively (depth ≤4) from its own folder and from domain component folders (`components/crm`, `components/sales`, `components/payments`, …). Shared-kit folders (`components/shared`, `ui`, `layout`, `master-data`, `documents`, `business`, `print`, `accounting/financial-report`) count toward _component usage_ but NOT toward the page's _style problems_ (those are reported once, in §6). Comments are stripped before counting.
- **LOC** = lines of page-owned code (page + co-located + domain components). Shared editors are counted in every page that uses them, so e.g. all sales document editors show ~2.1k.
- **Shell**: `MasterDataPage(→PageWorkspace)` = config-driven list (`components/master-data/master-data-page.tsx`, renders PageWorkspace + EnterpriseDataTable). `RecordHighlightsHeader` = detail header from `components/shared/detail-workspace.tsx` used without DetailWorkspace.
- **Table**: `EDT` = `EnterpriseDataTable` (`components/master-data/enterprise-data-table.tsx`, the shared list table; helpers in `components/shared/data-table`). `raw ui/table` = page-owned code imports `components/ui/table` directly. `hand <table>` = literal `<table>` element in page-owned code.
- **Style problems**: `palette` = Tailwind palette colors (text-green-600…); `hex` = hex/rgb literals; `arb` = arbitrary values (`w-[..]`, `text-[..]`, `grid-cols-[..]`); `physical` = left/right/ml/mr; `fixed-w` = `w-NN`/`min-w-NN`/`w-[..]` fixed widths (mobile overflow risk); `raw h1/h2` = headings outside PageHeader; `deco` = rounded-xl+/shadow-md+/gradients. No native `<select>` exists in any page-owned code; physical-direction classes are 0 outside comments.
- **Severity** 1 = token/kit-only change (inherits redesign from shared components); 2 = moderate page-level rework (raw tables, one-off layout, large bespoke surface); 3 = heavy redesign (hand-built tables, bespoke shell, key archetype with many one-offs).

## Headline findings

- The codebase is already largely token-clean: **0 native `<select>`**, **0 real physical left/right classes**, Tailwind palette colors only in the print kit, hex literals only as a duplicated brand-color fallback (3 pages). The redesign effort is therefore driven by **structure/consistency**, not by color cleanup.
- **EnterpriseDataTable is the de-facto list system** (85 routes: 45 via config-driven MasterDataPage, 40 direct). Redesigning EDT + MasterDataPage + PageWorkspace re-skins the majority of LIST pages at once.
- **All sales/purchasing document editors (14 routes) funnel through `CommercialDocumentEditor` + `DocumentLineTable`**; payments/refunds (5) through `FinancialTransactionEditor`; journal entries through `JournalEntryLinesGrid`. Three editor kits cover every DOC-EDITOR.
- Hot spots: investors module (hand-built `<table>` ×16 across 3 pages), `raw ui/table` in 27 routes, bespoke detail shells (products/[id], store-orders/[id]), duplicated `max-w-[1100px]` + hex brand fallback in customer/supplier/lead detail, auth + investor-public layouts full of arbitrary values.
