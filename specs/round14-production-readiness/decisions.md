# R14 decisions

Adopted by the implementation lead under the owner's 2026-10-07 brief. "Open" items carry a
recommended default that is implemented; the owner can override.

| Id   | Decision                                                                                                                                                                                                                                                                                          | Status                                                      |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| D1-1 | Sessions are server-side (`UserSession`), session cookie only, "remember me" removed, idle 120 min, absolute = `JWT_ACCESS_TTL`. Restart detection is best-effort (sessionStorage + BroadcastChannel); browsers that restore sessions can keep a session until idle/absolute expiry — documented. | Adopted                                                     |
| D1-2 | `next` after login honoured for signed-out deep links and session-expiry returns; logout never carries it.                                                                                                                                                                                        | Adopted                                                     |
| D2-1 | Effective permissions = (job-title template ∪ individual GRANTs) − individual DENYs, inside the existing resolver. Template changes apply live after an impact preview.                                                                                                                           | Adopted                                                     |
| D2-2 | New `shipping.assign_carrier`, migrated to holders of `shipping.edit`/`shipping.manage`.                                                                                                                                                                                                          | Adopted                                                     |
| D3-1 | Company store orders recognise revenue + stock issue + COGS at delivery/collection, not at full payment (replaces ADR-0017 payment gate). Reservation at shipment. Failures recorded on the order, never block the courier status.                                                                | Adopted (owner rule: "inventory must not wait for payment") |
| D3-2 | Applying the repair on Production creates invoices/movements/JEs for already-delivered orders = change to Production financial records. Dry run is run and reported; apply needs the owner's go-ahead.                                                                                            | **Open — owner**                                            |
| D3-3 | A delivered order later marked RETURNED is flagged `RETURN_PENDING`; the sales return is posted by a user (goods inspection), not automatically.                                                                                                                                                  | Adopted                                                     |
| D4-1 | Authorized advanced lookup shows full name + full phone (owner's explicit change); counts are company-wide numbers only.                                                                                                                                                                          | Adopted                                                     |
| D5-1 | Partner profit loss periods are not carried forward (alternative: carry forward against future profit).                                                                                                                                                                                           | **Open — owner (default implemented)**                      |
| D5-2 | One company profit pool, one closing frequency in R14; activity-scoped pools deferred.                                                                                                                                                                                                            | Adopted                                                     |
| D5-3 | Partner distribution accounts must be chosen in Settings → Accounting before the first close (no accounts are created automatically).                                                                                                                                                             | Adopted                                                     |
