## 1. أين تُضبط النسب

| ماذا                         | أين                                                                                                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| نسبة المنتجات ونسبة الخدمات  | **الوكلاء** ← الوكيل ← **الاتفاقيات** ← اتفاقية جديدة: «نسبة المنتجات (%)» و«نسبة الخدمات والدورات (%)» + «رسم شحن الوكيل» + تاريخ السريان. قبل **تفعيل** تظهر معاينة الحساب ونسبة كل صنف. |
| نوع الصنف (منتج / خدمة)      | **المنتجات** ← تعديل الصنف ← حقل «نوع الصنف» — مستقل عن تتبع المخزون؛ الدورات خدمات. قائمة المنتجات تُظهر «غير مصنّف» للمراجعة.                                                            |
| نسبة خاصة بصنف (بما فيها 0٪) | نموذج الصنف ← قسم **العمولة** ← «مصدر العمولة» = نسبة خاصة، النسبة، «تسري من» (اليوم أو بعده)؛ «اتباع اتفاقية الوكيل» للعودة. السجل محفوظ ولا يُعدَّل بأثر رجعي.                           |

ترتيب الحساب: النسبة الخاصة السارية ← نسبة نوع الصنف في الاتفاقية ← وإلا يُرفض الطلب (لا صفر
ضمنيًا). النسبة ونوع الصنف ورسم الشحن تُحفظ في الطلب عند إرساله؛ تغيير الإعدادات لاحقًا لا يمس
الطلبات السابقة.

## 2. مثال 200,000 (العمولة)

| البند                   | الحساب        | المبلغ     |
| ----------------------- | ------------- | ---------- |
| مبيعات المنتجات         |               | 100,000    |
| مبيعات الخدمات          |               | 100,000    |
| عمولة المنتجات          | 100,000 × 35٪ | 35,000     |
| عمولة الخدمات           | 100,000 × 25٪ | 25,000     |
| **إجمالي عمولة الشركة** |               | **60,000** |

العمولة تُحسب لكل سطر بنسبته ثم تُجمع، على صافي مبيعات الصنف دون الضريبة والشحن ورسم الخدمة.
**تكاليف شركات الشحن لا تُخصم أبدًا من أساس العمولة.** (اختبار قبول آلي على قاعدة بيانات حقيقية.)

## 3. الشحن: شحن العميل مقابل رسم الوكيل مقابل تكلفة الناقل

المثال المعتمد (دون ضريبة أو تسويات):

| البند                                           | المبلغ  |
| ----------------------------------------------- | ------- |
| مبيعات المنتج                                   | 1,000   |
| شحن العميل (ملك للشركة)                         | 100     |
| إجمالي المحصّل                                  | 1,100   |
| عمولة المنتج 35٪ — **عمولة الشركة**             | 350     |
| رسم شحن الوكيل المحدد مسبقًا                    | 100     |
| **الشحن المحتجز** (شحن العميل يسدّد رسم الوكيل) | 100     |
| تحتجز الشركة إجمالًا                            | 450     |
| **صافي مستحق الوكيل**                           | **650** |

- رسم شحن الوكيل = سعر الشحن في الاتفاقية لوجهة الطلب (الاستلام من المقر والرقمي = 0)، ويُثبَّت
  عند إرسال الطلب.
- في كشف الوكيل قيدان فقط: «عمولة» 350 و«شحن العميل المحتجز» 100 (مع بيان أنه سدّد رسم الشحن 100).
  **لا يُخصم 100 مرة ثانية.**
- **تكلفة شركة الشحن الفعلية** (مثلًا فاتورة الناقل 60): مصروف شحن على الشركة ولربحية الطلب فقط.
  فواتير الناقل (أساسية، إضافية لاحقة، إشعار دائن، «تم الدفع») **لا تُنشئ أي قيد على الوكيل**.
  مثال: فاتورة 60 + إضافية 20 − إشعار دائن 10 ← مستحق الوكيل يبقى 650.
- إن اختلف شحن العميل عن رسم الوكيل (تعديل يدوي) **يُرفض الطلب** ويُعرض المبلغان — معالجة الفرق
  بانتظار قراركم (انظر §6).

## 6. أسئلة بانتظار قراركم

1. **فرق الشحن:** إذا اختلف شحن العميل عن رسم الوكيل، من يتحمّل الفرق أو يستحقه؟ (أ) الوكيل

2. **«نوع/خدمة الشحن»:** هل تكفي الوجهة (دولة/مدينة) + شحن/استلام، أم تختلف الأسعار حسب شركة
   الشحن أو مستوى الخدمة؟
3. **حسابات D1** ما زالت مطلوبة لترحيل قيود الوكلاء في الإنتاج.
