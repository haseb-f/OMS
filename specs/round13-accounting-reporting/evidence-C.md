### API surface added

- `POST /fixed-assets/:id/dispose` accepts `counterpartyPartnerId` (supplier credit).
- `GET /fixed-assets/cost-addition-targets?search=` — Draft / Capitalized assets with PENDING periods.
- `GET /fixed-assets/:id` adds `costAdditions`, `purchaseReturn`, `disposalPartner`, `journalEntries.disposalSource`, `summary.costAdditions`.
- `POST /prepaid-expenses/:id/cancel` (`date`, `partnerId` | `receivingAccountId`) · `POST /prepaid-expenses/:id/recognize-remaining` (`date`) — permission `prepaid-expenses.edit`.
- `GET /prepaid-expenses/:id` adds closure fields, `journalEntries.refund` / `acceleration`, `summary.refundedAmount`.
- `GET /purchase-returns/returnable-summary/:invoiceId` items add `treatment`, `wholeLineOnly`, `returnBlockedReason`.
- Purchase invoice lines accept `linkedFixedAssetId`; taxes accept `isRecoverable`.
- New posting source types `PREPAID_REFUND`, `PREPAID_ACCELERATION` (journal type GENERAL; traceability → prepaid; web journal source labels en/ar).

### Not covered

- Non-recoverable tax on STANDARD / PREPAID lines still posts to VAT Input (O-2 scope is fixed-asset lines only).
- A cost-addition line cannot be returned on its own (the asset is disposed to the supplier instead); a return in a foreign currency of an asset / prepaid line is booked at the invoice's rate.
