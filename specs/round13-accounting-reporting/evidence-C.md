## API surface added

- `GET /fixed-assets/:id` → detail (rows with `journalEntry`, source invoice + line, `journalEntries`, `summary`).
- `GET /fixed-assets/:id/schedule-preview` (query overrides) · `POST /fixed-assets/schedule-preview` (unsaved form).
- `GET /fixed-assets/linkable-invoice-lines` · `POST|DELETE /fixed-assets/:id/invoice-line` (edit permission).
- `POST /fixed-assets/:id/dispose` accepts `disposalDate`.
- `GET /prepaid-expenses/:id` → detail · `POST /prepaid-expenses/schedule-preview` · `GET /prepaid-expenses/:id/activity` (real activity log; was a stub returning `[]`).
- `GET /purchase-invoices/:id` items carry `fixedAsset` / `prepaidExpense` links.
- Migration `20261006110000_r13_schedule_cancelled`: `AccountingScheduleStatus += CANCELLED`.
