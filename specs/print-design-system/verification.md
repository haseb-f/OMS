## Step 6 — rendered-PDF print review (2026-09-28)

**How it ran.** `tmp/print/render.mjs` opens each `/print/*` preview on the local web app (`next dev`, port 3001). The print job goes into localStorage the same way `usePrintEngine` puts it there. The script then calls Playwright `page.pdf({ preferCSSPageSize: true })`. `tmp/print/rasterize.mjs` rasterizes each PDF to PNG through the Edge PDF viewer. The evidence is in `tmp/print/pdf/*.pdf`, `tmp/print/png/*.png` and `tmp/print/summary.json` (page count, row count, overflow, page errors).

**Limitation (BLOCKED part).** The local API and database did not run. Docker Desktop would not start the engine: the backend failed on stale AF_UNIX socket files under `%LOCALAPPDATA%\Docker
un` and `%LOCALAPPDATA%\docker-secrets-engine`, which could not be deleted. I renamed both folders to `*.stale*-20260928`; nothing was deleted. Further Docker recovery was stopped, so no Postgres, no API and no DEMO-PRINT records exist. Instead, the payloads are hand-built in exactly the shape the builders emit, tagged `DEMO-PRINT-20260928`. The builders themselves are covered by `config/documents/commercial-print.spec.ts` and `package-slip-print.spec.ts`. The API → builder → print path for real records still needs one pass once the database is up.

**Defects found and fixed (print code only).**

1. RTL: LTR values rendered as blocks (`num` on a `dd` / `div` / `span` line) aligned to the left edge of Arabic sheets. This affected dates and references in the Document panel, the party phone and the slip phone. They are now an inline `<bdi class="num">`. Files: `print-blocks.tsx`, `package-slip-template.tsx`.
2. Bidi: an Arabic line in an English sheet, and the reverse, reordered its numbers. This affected table text cells, party and company address lines, and the slip's second-language line. They now use `<bdi dir="auto">`, and the slip's second-language line uses the other language's direction. Files: `print-table.tsx`, `print-blocks.tsx`, `package-slip-template.tsx`.
3. Report section and parent headings could end a page alone. They now use `break-after: avoid` (`theme/print.css`).
4. The index column wrapped at 2 digits on A5 and would wrap at 3 digits on A4. It is now 8 mm with no wrapping (`package-slip-template.tsx`, `document-print-template.tsx`).
5. A capped list printout stated the cap only as "120 rows / 5200" after the last row. It now reads "Showing 120 of 5200 rows — print limit reached…" in the header and at the end: new key `printDocument.rowCountCapped` in ar + en, used in `generic-list-print-template.tsx`.
