# Architecture Decisions

This file is an index of Architecture Decision Records (ADRs) for Mercury System.
Each decision is recorded as an individual, numbered file under `docs/decisions/`.

## Format

Each ADR follows this structure:

```
# ADR-<number>: <title>

Date: YYYY-MM-DD
Status: Proposed | Accepted | Superseded | Deprecated

## Context
What is the issue that we're seeing that motivates this decision?

## Decision
What is the change that we're proposing/have agreed to?

## Consequences
What becomes easier or harder as a result of this change?
```
