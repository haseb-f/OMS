# التقارير

المصدر: تنقل OMS + تحقق F7 + صفحات الكود (Coming Soon حيث ينطبق). العملة: **EGP**.

## التقارير المالية — عاملة (موثّقة)

المسار: `/reports/finance` — أيضاً رابط «الأستاذ العام» تحت المالية.

اختر نوع التقرير من القائمة. فلاتر شائعة: نطاق تاريخ، حساب، شريك.

| التقرير                               | الغرض                  | كيف تفسّره                                 | نتيجة DEMO                                    |
| ------------------------------------- | ---------------------- | ------------------------------------------ | --------------------------------------------- |
| ميزان المراجعة `trialBalance`         | مجموع مدين = دائن      | إن لم يتوازن فهناك خلل ترحيل               | متوازن؛ نطاق الجولة مدين/دائن 8922            |
| الأستاذ العام `generalLedger`         | حركة حساب              | الرصيد الختامي يطابق الميزان               | مطابق على AR/AP/إيراد/COGS/مخزون/استلام       |
| الميزانية `balanceSheet`              | أصول = خصوم + حقوق     | يجب `balanced`                             | ناجح في الجولة                                |
| قائمة الدخل `incomeStatement`         | إيراد − مصروف          | صافي الدخل يطابق أرباح الفترة في الميزانية | نطاق الجولة: إيراد 3090، مصروف 422، صافي 2668 |
| التدفق النقدي `cashFlow`              | حركة نقدية             | صافي التغير والرصيد الختامي                | يعمل (مثال: صافي تغير 2930)                   |
| كشف عميل `customerStatement`          | حركة ذمم مدينة         | الافتتاح + الحركات = الإغلاق               | أمثلة DEMO متطابقة مع القيود                  |
| كشف مورد `supplierStatement`          | حركة ذمم دائنة         | نفس المنطق للمورد                          | إغلاق مورد التجارب وفق F4/F7                  |
| تقادم مدين/دائن `arAging` / `apAging` | أعمار الأرصدة المفتوحة | مجموع التقادم ≈ الفواتير المفتوحة          | موثّق لعملاء/مورد DEMO                        |

تقارير إضافية ظاهرة في واجهة المالية (من الكود): تقرير يومية، كشف حساب، توفر نقدية — **لم تُفصَّل فحوصاتها في ملخص F7**؛ لا تعتمد عليها دون تحقق ذاتي.

## تفسير سريع لأرقام DEMO

- بعد مرتجع عميل دون استرداد نقدي: كشف العميل قد يُظهر رصيداً دائناً (سالب مدينة) بينما التقادم للفواتير المفتوحة = 0.
- بعد مرتجع مورد مدفوع: المورد قد يظهر مديناً للشركة بمبلغ المرتجع حتى تُسوّى حركة لاحقة.
- عمليات F5 اللاحقة تغيّر أرصدة الشركاء (مثلاً فاتورة مختبر غير مدفوعة 240 على عميل B2B) — استخدم كشوف F7 لا الأرقام القديمة وحدها.
