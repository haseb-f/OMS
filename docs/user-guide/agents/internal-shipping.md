# الشحن الداخلي — طلبات الوكلاء

دليل موظفي الشحن في الشركة لتنفيذ **طلبات الوكلاء**. طلب الوكيل يدخل نفس قوائم **طلبات المتجر** و**الشحن** ويُنفَّذ بنفس الخطوات الواردة في [دليل الشحن](../roles/shipping.md)، مع فروق محددة: البضاعة ملك الوكيل، لا فاتورة من الشركة، والمرتجع يُسجَّل بـ **«استلام مرتجع»**.

| البند          | القيمة                                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| الصلاحيات      | `store-orders.view`، `shipping.view` / `shipping.edit` (و`shipping.manage` لبدء الشحنة)؛ `agents.view` لإظهار فلتر **الوكيل** |
| من يحرّك الشحن | **شحن الشركة فقط** — الوكيل لا يستطيع تغيير أي حالة شحن                                                                       |
| المرجع         | [`spec.md`](../../../specs/agents-fulfillment-partners/spec.md) §4–§6، §8                                                     |

## المهام

### 1) التعرف على طلبات الوكلاء

1. **المبيعات ← طلبات المتجر** أو **الشحن ← الشحن**.
2. عمود **الوكيل** يعرض اسم الوكيل ورقمه (و«—» لطلبات الشركة). استخدم فلتر **الوكيل** لعرض وكيل واحد (يظهر الفلتر لمن يملك `agents.view`).
3. في صفحة الطلب تظهر شارة **«طلب وكيل»** وبطاقة **«تفصيل السعر»**: البضاعة، الخصم (للعلم)، الضريبة، **رسوم الشحن على العميل** (سعر الاتفاقية / مبلغ يدوي مع **سبب التعديل** / بلا شحن)، رسوم الخدمة، **إجمالي المستحق**.
4. الملاحظة: «طلب وكيل — بلا فاتورة من الشركة. البضاعة ملك الوكيل، ورسومنا تُسجل في كشف حساب الوكيل.» لا تستخدم **إصدار فاتورة** لطلب وكيل (مرفوض).

(صورة: قائمة الشحن مع عمود وفلتر الوكيل)
(صورة: طلب وكيل — شارة «طلب وكيل» وتفصيل السعر)

### 2) قواعد الجاهزية (كما لطلبات الشركة)

| الطلب                                   | يمكن تجهيزه؟                         |
| --------------------------------------- | ------------------------------------ |
| مدفوع مسبقاً + إبلاغ **كامل**           | **نعم** — دون انتظار المالية         |
| مدفوع مسبقاً + إبلاغ **جزئي** أو لا شيء | **لا**                               |
| **الدفع عند الاستلام** (شحن)            | نعم دون إبلاغ                        |
| **استلام من المقر** مدفوع مسبقاً        | **جاهز للاستلام** بعد إبلاغ كامل فقط |
| استلام من المقر، الدفع عند الاستلام     | نعم دون إبلاغ                        |

- الحد يُقاس على **الإجمالي المستحق** (شامل الشحن). الإبلاغ الكامل عن طلب 1,100 يعني 1,100، لا 1,000.
- الإبلاغ إلى **حساب الوكيل** يحتسب للجاهزية مثل حساب الشركة؛ التحقق المالي منفصل.
- الدفع لا يغيّر حالة الشحن أبداً.

### 3) الشحن والتسليم

1. **بدء الشحنة** («جاهز للشحن») — **تغيير حالة الشحن** من **طلبات المتجر** (`shipping.manage`).
2. في **الشحن** اختر للصف **تم الشحن** وأدخل **رقم التتبع** و**شركة الشحن**.
3. عند الوصول اختر **تم التسليم**.

| الانتقال        | ما يحدث تلقائياً لطلب الوكيل                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **تم الشحن**    | صرف المخزون **مرة واحدة** من مخزون الوكيل (حركة بيع/تسليم)؛ **رسم شحن** الاتفاقية على الوكيل (مثلاً 30)                           |
| **تم التسليم**  | إن كانت العمولة تُستحق عند «تسليم الطلب / استلامه»: **العمولة**، **شحن عميل محتجز** (إن كان للشركة)، **رسم الخدمة** في كشف الوكيل |
| إلغاء قبل الشحن | لا رسوم ولا حركة مخزون                                                                                                            |

- إعادة الشحن (شحنة ثانية) تظهر للوكيل «الشحنة رقم 2 — إعادة شحن».

(صورة: قائمة الشحن — تم الشحن لطلب وكيل)

### 4) ملصق الطرد (A5) — مبلغ التحصيل يشمل الشحن

**طباعة ملصق الطرد (A5)** من صفحة الطلب. تعليمة التحصيل تعتمد **الإجمالي المستحق**:

| الطلب                                                 | على الملصق                                     |
| ----------------------------------------------------- | ---------------------------------------------- |
| الدفع عند الاستلام، «الشحن يُضاف» 1,000 + 100         | **«يُحصّل مبلغ 1,100»**                        |
| الدفع عند الاستلام، «السعر شامل الشحن» 1,000 شامل 100 | **«يُحصّل مبلغ 1,000»**                        |
| الدفع عند الاستلام مع إبلاغ مسبق بـ 400 من 1,100      | «يُحصّل مبلغ 700»                              |
| مدفوع مسبقاً بإبلاغ كامل                              | «لا يُحصّل مبلغ»                               |
| مدفوع مسبقاً بإبلاغ جزئي                              | «الدفع غير مكتمل — لا يُسلَّم قبل تأكيد الدفع» |

(صورة: ملصق طرد A5 لطلب وكيل الدفع عند الاستلام — يُحصّل 1,100)

### 5) تسليم طلب الاستلام من المقر

1. افتح الطلب ← قسم **الاستلام من الفرع** ← **جاهز للاستلام**.
2. عند حضور العميل ← **تسجيل الاستلام** ← تأكيد.

- التسليم هنا = الشحن + التسليم معاً: يُصرف المخزون، ويُستحق ما يُستحق عند التسليم. لا يُضاف شحن (الشحن = 0).
- حالة الاستلام **«مرتجع»** مرفوضة لطلبات الوكلاء: «مرتجعات طلبات الوكلاء تُسجَّل من "استلام مرتجع الوكيل" وليس من حالة الاستلام» — استخدم المهمة 6.

### 6) استلام مرتجع

1. افتح الطلب ← بطاقة **المرتجعات** ← **استلام مرتجع** (`shipping.edit`).
2. في «استلام مرتجع — {الطلب}» أدخل **كمية المرتجع** لكل منتج (أرقام صحيحة، لا تتجاوز **المطلوب** − **المرتجع**).
3. **المستودع** (مطلوب) و**السبب**.
4. **الشحنة المرتجعة**: اختر «الشحنة رقم N» التي عادت (أو «غير مرتبط بشحنة»).
5. **احتساب رسوم المرتجع وفق الاتفاقية** — الافتراضي: تُحتسب عند أول استلام للشحنة، أو (بدون شحنة) عند أول مرتجع للطلب فقط. غيّر الاختيار فقط لحالة خاصة (مثل طرد ثانٍ بعد إعادة شحن).
6. **استلام مرتجع** ← «تم تسجيل المرتجع».

| ما يحدث تلقائياً                                                                      |
| ------------------------------------------------------------------------------------- |
| يعود المخزون إلى مخزون **الوكيل** في المستودع المختار                                 |
| **رسم مرتجع** على الوكيل مرة واحدة لكل شحنة مرتجعة (مثلاً 25)                         |
| **عكس عمولة** للجزء المرتجع إذا كانت الاتفاقية «عكس العمولة» وكانت العمولة قد استُحقت |
| شحن العميل المحتجز **لا يُعكس** (خدمة الشحن أُدِّيت)                                  |
| رد المال للعميل **ليس** من عمل الشحن — تسجله المالية                                  |

(صورة: نافذة «استلام مرتجع» مع الشحنة المرتجعة ورسوم المرتجع)

## مثال شامل (EGP)

اتفاقية الوكيل: عمولة 10% عند التسليم، الشحن على العميل للشركة، رسم شحن 30، رسم مرتجع 25، عكس العمولة عند المرتجع.

1. طلب وكيل مدفوع مسبقاً «السعر شامل الشحن» 1,000 شامل 100، إبلاغ **كامل** 1,000 إلى حساب الشركة ← يظهر في **الشحن** بشارة الوكيل ويُجهَّز دون انتظار المالية.
2. **تم الشحن** ← صرف المخزون + رسم شحن **30** على الوكيل.
3. **تم التسليم** ← عمولة 10% × 900 = **90** + شحن محتجز **100**. بعد تحقق المالية من 1,000: رصيد الوكيل 1,000 − 90 − 100 − 30 = **780**.
4. عاد الطرد كاملاً ← **استلام مرتجع** (الشحنة رقم 1، رسوم المرتجع محددة) ← المخزون يعود للوكيل، عكس عمولة **+90**، رسم مرتجع **−25** ← الرصيد 780 + 90 − 25 = **845** (قبل أي رد مال للعميل، تسجّله المالية).

## أخطاء شائعة

| السلوك                            | المعالجة                                   |
| --------------------------------- | ------------------------------------------ |
| لا أرى فلتر **الوكيل**            | يحتاج `agents.view` — اطلبه من مدير النظام |
| «تعذر تحديث 1 طلبات» عند التجهيز  | إبلاغ جزئي أو غير موجود لطلب مدفوع مسبقاً  |
| رفض **إصدار فاتورة** لطلب وكيل    | متوقع — طلبات الوكلاء بلا فاتورة من الشركة |
| رفض حالة الاستلام «مرتجع»         | استخدم **استلام مرتجع**                    |
| «أكثر من المتبقي» في كمية المرتجع | الكمية تتجاوز المشحون ناقص المرتجع سابقاً  |
