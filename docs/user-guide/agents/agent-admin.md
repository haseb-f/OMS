# مدير الوكيل (Agent Admin)

دليل لمدير الوكيل في **بوابة الوكيل**: شركة خارجية تملك بضاعتها المخزّنة لدينا، ونحن نستلم الطلبات ونجهّزها ونشحنها ونحصّلها مقابل عمولة ورسوم متفق عليها. مدير الوكيل **يتابع** ويدير فريقه، لكنه **لا يعتمد** أي عملية مالية ولا يغيّر شروط الاتفاقية.

| البند            | القيمة                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| الإنتاج          | https://oms.haseb.org (صفحة الدخول نفسها التي يستخدمها موظفو الشركة)                                                     |
| الدور            | **مدير الوكيل** (`ADMIN`)                                                                                                |
| القائمة الجانبية | **لوحة الوكيل** · **العملاء المحتملون** · **الطلبات** · **المخزون** · **كشف الحساب** · **المدفوعات للوكيل** · **الفريق** |
| نطاق السجلات     | **«تُعرض كل سجلات الوكيل.»** — كل طلبات وعملاء وكالتك، ولا شيء من وكيل آخر أو من الشركة                                  |
| العملة           | عملة التسوية في اتفاقيتك (في الأمثلة: **EGP**)                                                                           |
| المرجع           | [`specs/agents-fulfillment-partners/spec.md`](../../../specs/agents-fulfillment-partners/spec.md) §3، §8–§10             |

| الصفحة               | الغرض                                                      | الصلاحية                                |
| -------------------- | ---------------------------------------------------------- | --------------------------------------- |
| **لوحة الوكيل**      | تقدم التنفيذ، المبيعات والرصيد، أحدث الطلبات               | `agent.dashboard.view`                  |
| **الطلبات**          | كل طلبات الوكيل مع الدفع المُبلَّغ وحالة المالية والتنفيذ  | `agent.orders.view`                     |
| **المخزون**          | منتجاتك المحفوظة لدينا حسب المستودع                        | `agent.stock.view`                      |
| **كشف الحساب**       | الرسوم والتحصيلات والمدفوعات والرصيد الجاري — طباعة وتصدير | `agent.statement.view`                  |
| **المدفوعات للوكيل** | ما صرفته الشركة لك وما غطّاه كل صرف (للقراءة فقط)          | `agent.payouts.view`                    |
| **الفريق**           | مستخدمو وكالتك؛ إضافة وإيقاف مستخدمي المبيعات              | `agent.team.view` / `agent.team.manage` |

## المهام

### 1) الدخول لأول مرة وتغيير كلمة المرور المؤقتة

تسلّمك الشركة **اسم المستخدم** و**كلمة مرور مؤقتة** (تظهر لمن أنشأ الحساب مرة واحدة فقط).

1. افتح https://oms.haseb.org وأدخل اسم المستخدم أو البريد وكلمة المرور المؤقتة ← **تسجيل الدخول**.
2. تظهر صفحة **«عيّن كلمة المرور الخاصة بك»** — «سجّلت الدخول بكلمة مرور مؤقتة. اختر كلمة مرورك للمتابعة.» لا يمكن فتح أي صفحة أخرى قبل إكمالها.
3. أدخل **كلمة المرور الحالية (المؤقتة)**، ثم **كلمة المرور الجديدة** و**تأكيد كلمة المرور الجديدة** (8 أحرف على الأقل، ومختلفة عن المؤقتة).
4. اضغط **تغيير كلمة المرور** ← «تم تغيير كلمة المرور.» ← تنتقل إلى **لوحة الوكيل**.

- لتغييرها لاحقاً: قائمة المستخدم أعلى الشاشة ← **تغيير كلمة المرور**.
- إذا أوقفت الشركة الوكالة أو حسابك يُقطع وصولك فوراً، حتى لو كانت الجلسة مفتوحة.

(صورة: صفحة «عيّن كلمة المرور الخاصة بك»)

### 2) قراءة لوحة الوكيل

1. افتح **لوحة الوكيل**.
2. **تقدم التنفيذ:** كل الطلبات · بانتظار الشحن · تم الشحن · مكتملة · بها مرتجعات · ملغاة.
3. **المبيعات والرصيد:**

| البطاقة                     | معناها                                               |
| --------------------------- | ---------------------------------------------------- |
| **المبيعات (بدون الشحن)**   | قيمة البضاعة فقط — هي أساس العمولة                   |
| **رسوم الشحن على العملاء**  | ما دفعه العملاء مقابل الشحن (منفصل عن المبيعات)      |
| **إجمالي قيمة الطلبات**     | المبيعات + الشحن + رسوم الخدمة = ما يدفعه العملاء    |
| **المرتجعات**               | قيمة البضاعة المرتجعة                                |
| **تحصيلات بانتظار المالية** | دفعات مُبلَّغة لم تتحقق منها المالية بعد (عددها)     |
| **رصيد معلّق**              | مبالغ مستلمة لكنها لم تصبح قابلة للصرف بعد           |
| **الأموال المتاحة**         | ما يمكن للشركة صرفه لك الآن                          |
| **الرصيد**                  | إجمالي ما تستحقه لدى الشركة (موجب) أو ما عليك (سالب) |
| **المدفوعات للوكيل**        | عدد عمليات الصرف ومجموعها                            |

4. **أحدث الطلبات** ← **عرض الكل** يفتح قائمة الطلبات.

(صورة: لوحة الوكيل — تقدم التنفيذ والمبيعات والرصيد)

### 3) متابعة الطلبات وتقدم التنفيذ

1. **الطلبات** ← ابحث برقم الطلب أو العميل أو الجوال، واستخدم الفلاتر **الدفع المُبلَّغ**، **حالة المالية**، **التنفيذ**، **الطريقة**.
2. افتح الطلب. تجد:
   - **تفصيل السعر:** المنتجات، الخصم، الضريبة، الشحن، رسوم الخدمة، **الإجمالي المستحق**.
   - **تقدم التنفيذ:** تم إنشاء الطلب ← تم الشحن ← مكتمل (أو ملغي)، ولكل شحنة: **شركة الشحن**، **رقم التتبع**، **الحالة**، **آخر تحديث**.
   - **الدفع:** «مُبلَّغ من المبيعات (بانتظار تحقق المالية)»، «تحققت المالية»، **المتبقي للإبلاغ**، ولكل دفعة: **الوجهة** (حساب الشركة / حساب الوكيل)، **المرحلة**، **الإثبات**.
   - **المرتجعات** و**السجل الزمني**.

- **حالة الدفع ≠ حالة الشحن.** الإبلاغ عن الدفع لا يعني أن المالية تحققت، ولا يغيّر الشحن. الشحن يحرّكه موظفو الشحن في الشركة فقط.

(صورة: تفاصيل طلب وكيل — تفصيل السعر وتقدم التنفيذ والدفع)

### 4) متابعة المخزون

1. **المخزون** — لكل منتج ومستودع: **الرصيد الفعلي**، **المحجوز**، **المتاح** (= الفعلي − المحجوز)، **المشحون**، **المرتجع**، مع صف **الإجماليات**.
2. استلام بضاعتك في مستودعاتنا تسجّله الشركة؛ يظهر هنا فور تسجيله. خروج البضاعة يُسجَّل عند **الشحن** (أو تسليم طلب الاستلام من المقر)، وعودتها عند **استلام المرتجع**.

(صورة: صفحة المخزون)

### 5) قراءة كشف الحساب

**قاعدة الإشارة:** «**الرصيد الموجب = مستحق لك لدى الشركة، السالب = مستحق للشركة عليك.**»

| العمود            | المعنى                                                 |
| ----------------- | ------------------------------------------------------ |
| **مدين (للشركة)** | خصم من رصيدك: عمولة، رسوم، شحن محتجز، صرف لك           |
| **دائن (لك)**     | إضافة لرصيدك: تحصيل استلمته الشركة، عكس عمولة، عكس صرف |
| **الرصيد**        | الرصيد الجاري بعد كل سطر                               |
| **متاح من**       | تاريخ صيرورة التحصيل قابلاً للصرف                      |

1. **كشف الحساب** ← اختر الفترة (أو **كل التواريخ**).
2. أعلى الكشف أربعة أقسام: **المبيعات** · **العمولة** (أساس العمولة، نسبة العمولة، العمولة) · **الخصومات** · **التحصيلات** (حصّلته الشركة / حصّلته أنت) · **الموقف** (معلّق، متاح، مصروف، الرصيد).
3. الأسطر: **الرصيد الافتتاحي** ← القيود ← **الرصيد الختامي**.
4. **طباعة** (عرضي A4، بشعار الشركة وتاريخ الطباعة وأرقام الصفحات) أو التصدير من خيارات الجدول.

**ما يظهر مع الشحن وبدونه**

| البند                            | طلب «السعر شامل الشحن» 1,000 شامل 100 | طلب «الشحن يُضاف» 1,000 + 100 |
| -------------------------------- | ------------------------------------- | ----------------------------- |
| المبيعات (بدون الشحن)            | 900                                   | 1,000                         |
| رسوم الشحن على العملاء           | 100                                   | 100                           |
| إجمالي قيمة الطلبات (شامل الشحن) | 1,000                                 | 1,100                         |
| أساس العمولة (10%)               | 900 ← عمولة 90                        | 1,000 ← عمولة 100             |

طلب **استلام من المقر** أو منتج رقمي/خدمة: الشحن = 0 ويظهر «بدون شحن».

**التحصيل عند الشركة مقابل التحصيل عندك**

| من استلم المال                  | في الكشف                                      | أثره على رصيدك                         |
| ------------------------------- | --------------------------------------------- | -------------------------------------- |
| **حساب الشركة**                 | «تحصيل استلمته الشركة» — دائن (لك)            | يزيد رصيدك بعد تحقق المالية            |
| **حساب الوكيل** (دفع لك مباشرة) | «تحصيل لديك (مذكرة)» — سطر **مذكرة** بلا مبلغ | **لا يغيّر الرصيد** — المال عندك أصلاً |

- الطلب نفسه لا يضيف شيئاً لرصيدك؛ **المال المستلم فقط** يُضاف، ومرة واحدة.
- الخصومات على طلب دفع عميله لك مباشرة تبقى مستحقة للشركة، فيصبح رصيدك سالباً بقدرها.

**أساس العمولة والخصومات** (حسب اتفاقيتك — لا شيء افتراضي):

| الخصم                        | متى يُسجَّل                                                                   |
| ---------------------------- | ----------------------------------------------------------------------------- |
| **العمولة**                  | عند حدث الاستحقاق (التسليم/الاستلام، أو تحقق المالية) = النسبة × أساس العمولة |
| **شحن العملاء المحتجز**      | عند الاستحقاق، إذا كانت رسوم الشحن على العميل «تعود إلى الشركة»               |
| **رسوم الشحن**               | عند الشحن — رسم ثابت لكل شحنة                                                 |
| **رسوم الخدمة**              | عند الاستحقاق — رسم لكل طلب، ورسوم الخدمة على العميل إن وُجدت                 |
| **رسوم مزود الدفع**          | عند تسوية مزود الدفع، إذا كنت تتحملها                                         |
| **رسوم المرتجعات**           | عند استلام مرتجع — مرة واحدة لكل شحنة مرتجعة                                  |
| **المبالغ المستردة للعملاء** | إذا ردّت الشركة مالاً لعميل من طلباتك                                         |

- **أساس العمولة** = صافي البضاعة بعد الخصم التجاري، **دون** الضريبة ورسوم الشحن ورسوم الخدمة.

(صورة: كشف حساب الوكيل — الملخص والأسطر)

### 5أ) تقرير العمولة

من القائمة ← **تقرير العمولة**: لكل صنف مبيعاته ونوعه (منتج / خدمة) ونسبته ومصدرها والعمولة والمعكوس منها؛ ولكل طلب **شحن العميل** (للشركة) و**رسم شحن الوكيل** و**المحتجز** الذي يسدّده؛ وملخص: عمولة المنتجات، عمولة الخدمات، إجمالي العمولة، الشحن المحتجز، **صافي مستحقك** — ومنفصلاً **الموقف النقدي** (المحصّل، المعلّق، المتاح للصرف، المصروف). المستحق ليس نقدًا متاحًا.

مثال: منتجات 1,000 + شحن 100 = 1,100 حصّلتها الشركة؛ العمولة 35٪ = 350؛ رسم الشحن 100 يسدّده شحن العميل المحتجز 100؛ **مستحقك 650** — دون خصم 100 أخرى.

### 6) عرض المدفوعات للوكيل (للقراءة فقط)

1. **المدفوعات للوكيل** — لكل صرف: **رقم الصرف**، **التاريخ**، **المبلغ**، **الحالة** (مؤكَّد / معكوس)، **المرجع**، **صُرف من**.
2. افتح الصرف لترى **القيود التي غطّاها هذا الصرف** و**الإثبات** (إيصال التحويل).
3. الصرف تنفّذه مالية الشركة وحدها؛ لا يوجد زر صرف في البوابة. الصرف المعكوس يعيد المبلغ إلى رصيدك («عكس صرف» دائن).

(صورة: تفاصيل صرف مع القيود المغطاة)

### 7) إدارة الفريق (ضمن الصلاحيات المفوّضة)

إدارة الفريق تحتاج صلاحية **إدارة الفريق** التي تضيفها لك الشركة. بدونها تعرض صفحة **الفريق** المستخدمين فقط.

1. **الفريق** ← **مستخدم مبيعات جديد** ← **الاسم الكامل**، **اسم المستخدم**، **البريد الإلكتروني**، **الجوال**.
2. احفظ ← «تم إنشاء المستخدم {الاسم}». تظهر **كلمة مرور مؤقتة مرة واحدة** — سلّمها للمستخدم؛ سيُطلب منه تغييرها عند أول دخول.
3. **تعديل الصلاحيات:** «يمكنك تفويض الصلاحيات التي تملكها فقط. إدارة الفريق لا تُفوَّض.» ← «تم حفظ الصلاحيات.»
4. **إيقاف** (يُسجَّل خروجه فوراً) / **تفعيل** / **إعادة تعيين كلمة المرور** (كلمة مؤقتة جديدة تُعرض مرة واحدة).

- مستخدم المبيعات يرى افتراضياً **سجلاته فقط** («تُعرض سجلاتك أنت فقط.»)، إلا إذا فوّضته «رؤية كل سجلات الوكيل».

(صورة: الفريق — مستخدم مبيعات جديد وكلمة المرور المؤقتة)

## ما لا يستطيعه مدير الوكيل

| الإجراء                                                 | من ينفّذه                             |
| ------------------------------------------------------- | ------------------------------------- |
| تغيير نسبة العمولة أو الرسوم أو أي شرط في الاتفاقية     | الشركة (اتفاقية جديدة)                |
| التحقق من دفعة، اعتماد تحصيل، صرف أو عكس صرف، تسوية     | مالية الشركة                          |
| تغيير حالة الشحن (تم الشحن / تم التسليم) أو تسجيل مرتجع | شحن الشركة                            |
| إدارة مستخدم **مدير الوكيل** أو صلاحياته هو             | الشركة                                |
| تفويض «إدارة الفريق» لمستخدم مبيعات                     | غير ممكن                              |
| إعادة تفعيل مستخدم أوقفته الشركة                        | الشركة                                |
| رؤية وكيل آخر أو صفحات الشركة الداخلية                  | غير ممكن — «الوصول مرفوض» / غير موجود |

## مثال شامل (EGP)

اتفاقية: عمولة **10%** تُستحق عند **تسليم الطلب / استلامه**، رسوم الشحن على العميل تعود إلى **الشركة**، رسم الشحن لكل شحنة **30**، رسم الخدمة لكل طلب **0**، رسم المرتجع **25**.

طلب **مدفوع مسبقاً**، «السعر شامل الشحن»: **1,000 شامل 100 شحن = 900 منتجات + 100 شحن**. العميل دفع 1,000 إلى **حساب الشركة**.

| الخطوة                  | سطر الكشف            | مدين (للشركة) | دائن (لك) | الرصيد  |
| ----------------------- | -------------------- | ------------- | --------- | ------- |
| الشحن                   | رسوم شحن             | 30            |           | −30     |
| تحقق المالية من 1,000   | تحصيل استلمته الشركة |               | 1,000     | 970     |
| التسليم (حدث الاستحقاق) | عمولة 10% × 900      | 90            |           | 880     |
| التسليم                 | شحن عميل محتجز       | 100           |           | **780** |

**التحقق:** 1,000 − 90 − 100 − 30 = **780** مستحق لك. يصبح **متاحاً** بعد استلام الشركة للمال فعلاً (وتسوية المزود إن وُجد)، والتسليم، ومرور مدة حجز الصرف. إذا صرفت لك المالية 500 يبقى **280**.

نفس الطلب لو دفع العميل **لحسابك مباشرة**: سطر «تحصيل لديك (مذكرة)» بلا مبلغ، والخصومات 90 + 100 + 30 = 220 ← الرصيد **−220** (مستحق للشركة عليك)، يُخصم من تحصيلات لاحقة.

## أخطاء شائعة

| السلوك                                      | السبب / المعالجة                                                |
| ------------------------------------------- | --------------------------------------------------------------- |
| كل صفحة تعيدني إلى تغيير كلمة المرور        | كلمة المرور ما زالت مؤقتة — أكمل الخطوة 1                       |
| الطلب «مدفوع (مُبلَّغ)» لكن الرصيد لم يتغير | الإبلاغ ≠ تحقق المالية؛ الرصيد يتغير بعد التحقق فقط             |
| الرصيد موجب لكن «الأموال المتاحة» صفر       | المال لم يُسوَّ بعد، أو الطلب لم يُسلَّم، أو مدة الحجز لم تنتهِ |
| لا أرى زر **مستخدم مبيعات جديد**            | لا تملك «إدارة الفريق» — اطلبها من الشركة                       |
| رسالة عند تفعيل مستخدم                      | المستخدم أوقفته الشركة؛ الشركة وحدها تعيد تفعيله                |
