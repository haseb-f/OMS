# المالية الداخلية — الوكلاء

دليل المالية في الشركة لوحدة **الوكلاء**: الاتفاقيات، وجهات الدفع، التحقق من التحصيلات، التسويات، الصرف، الاسترداد، التسويات اليدوية، وقيود الوكلاء المعلقة. البضاعة ملك الوكيل، فهي **ليست إيراد مبيعات للشركة**؛ إيرادنا هو العمولة والرسوم والشحن المحتجز فقط.

| البند            | القيمة                                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| القائمة الجانبية | **الوكلاء ← الوكلاء** · **الوكلاء ← تحصيلات الوكلاء** · **المالية ← الإعداد والفترات ← إعدادات الحسابات**                                                     |
| مساحة عمل الوكيل | **نظرة عامة** · **الاتفاقيات** · **وجهات الدفع** · **فريق الوكيل** · **المنتجات والمخزون** · **الطلبات** · **كشف الحساب** · **المدفوعات للوكيل**              |
| الصلاحيات        | `agents.view`/`edit`، `agents.agreements.manage`، `agents.finance.view`/`verify`/`adjust`/`post`، `agents.payouts.create`/`reverse`، `agents.statement.print` |
| قاعدة الإشارة    | «الرصيد = ما نستحقه للوكيل. الرصيد الموجب مستحق للوكيل، والرصيد السالب يعني أن الوكيل مدين لنا.»                                                              |
| المرجع           | [`spec.md`](../../../specs/agents-fulfillment-partners/spec.md) §2، §7–§9، §11 (مع «Finance notes»)                                                           |

## المهام

### 0) إعداد الوكيل (مرة واحدة)

1. **الوكلاء** ← **وكيل جديد** ← الاسم، الاسم القانوني، التواصل، **عملة التسوية** («يُنشأ رقم الوكيل تلقائيًا.» مثل `AG-0001`) ← «تم إنشاء الوكيل {الرقم}».
2. عملة التسوية لا تتغير بعد إنشاء أول اتفاقية.
3. المنتجات: **المنتجات ← تعديل ← التصنيف ← الوكيل المالك** (ما دام المنتج بلا حركة مخزون وبلا سطر طلب؛ بعدها يُقفل).
4. البضاعة: تبويب **المنتجات والمخزون** ← **استلام مخزون** ← المنتج، المستودع، الكمية، المرجع ← «تم استلام المخزون».
5. المستخدمون: تبويب **فريق الوكيل** ← **إضافة مستخدم** (مدير الوكيل / مبيعات الوكيل؛ «إدارة الفريق» صلاحية إضافية) — كلمة المرور المؤقتة تظهر مرة واحدة.

### 1) الاتفاقية — كل شرط صريح

1. تبويب **الاتفاقيات** ← **اتفاقية جديدة** ← «اتفاقية جديدة (مسودة)».
2. أدخل كل الحقول — **لا توجد قيم افتراضية** («أكمل جميع الشروط قبل الحفظ.»):

| القسم             | الحقل                                                                                     | مثال الدليل           |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------- |
| الفترة            | **تسري من** / **تسري حتى (شاملة)** (فارغ = مفتوحة)                                        | 2026-09-01 / فارغ     |
| العمولة           | **نسبة العمولة (%)** — على صافي البضاعة دون الضريبة والشحن ورسوم الخدمة                   | 10                    |
|                   | **تُستحق العمولة عند**: تسليم الطلب / استلامه — أو — تحقق المالية من الدفع                | تسليم الطلب / استلامه |
|                   | **العمولة على البضاعة المرتجعة**: عكس العمولة / الاحتفاظ بالعمولة                         | عكس العمولة           |
| الرسوم على الوكيل | **رسوم الشحن على العميل تعود إلى**: الشركة / الوكيل                                       | الشركة                |
|                   | **رسم الشحن لكل شحنة** · **رسم المرتجع لكل شحنة** · **رسم الخدمة لكل طلب** (0 إن لم يوجد) | 30 · 25 · 0 (مثال)    |
| المدفوعات والصرف  | **رسوم مزوّد الدفع يتحملها**: الوكيل / الشركة                                             | الوكيل                |
|                   | **يمكن للعملاء الدفع للوكيل مباشرة**                                                      | نعم                   |
|                   | **مدة حجز الصرف (أيام)**                                                                  | 7                     |

3. **أسعار الشحن** ← **إضافة سعر**: الدولة، المدينة (فارغة = الدولة كلها)، المبلغ. سطر المدينة يتقدم على الدولة. وجهة بلا سعر تحتاج مبلغاً يدوياً بصلاحية وسبب.
4. **تفعيل** ← «تفعيل الاتفاقية {الرقم}؟» ← «تم تفعيل الاتفاقية».

- **لا تداخل:** لا تُفعَّل اتفاقيتان نشطتان لنفس الفترة.
- **الثبات:** «الاتفاقيات النشطة والمنتهية للقراءة فقط.» لتغيير أي شرط: **إنهاء الاتفاقية** (آخر يوم شامل) ثم اتفاقية جديدة تبدأ في اليوم التالي.
- **اللقطة:** كل طلب يحفظ شروط الاتفاقية التي قُدِّم بها؛ تغيير الاتفاقية لا يمس الطلبات أو قيود الكشف السابقة.

(صورة: نموذج الاتفاقية — كل الشروط)

### 2) وجهات الدفع

1. تبويب **وجهات الدفع** ← **إضافة وجهة** ← **طريقة الدفع**، **المبلغ يذهب إلى** (حساب الشركة / الوكيل (مباشرة))، **التسمية** (تظهر لمبيعات الوكيل)، **بيانات الحساب**.
2. وجهة «الوكيل (مباشرة)» تتطلب أن تسمح الاتفاقية السارية بذلك، وإلا: «الاتفاقية السارية لا تسمح بوجهات الوكيل…».
3. **إيقاف** الوجهة يمنع اختيارها في الإبلاغات الجديدة فقط.

### 3) التحقق من الدفعات إلى حساب الشركة

نفس مسار المالية المعتاد ([المالية — 1 و1أ](../roles/finance.md)): **مراجعة المدفوعات** ← **تأكيد وترحيل**، أو **مطابقة المدفوعات** للطرق التي تتطلب مطابقة.

- لطلب الوكيل، سند القبض يُرحِّل: **مدين** حساب وسيط الطريقة / **دائن** «مستحقات الوكلاء (التزام)» (الشريك = الوكيل) — لا ذمم عميل ولا إيراد مبيعات.
- في كشف الوكيل: «تحصيل مستلم» دائن. مفتاحه سند القبض، فلا يُضاف مرتين؛ إلغاء المطابقة يسجّل «عكس تحصيل» ثم المطابقة الصحيحة تضيفه مرة واحدة.
- **قبل ضبط حسابات الوكلاء (D1)** يُمنع التحقق برسالة: «Agent posting accounts are not configured (Accounting Settings → Agent funds payable).» — انظر المهمة 9.
- دفعة إلى **حساب الوكيل** تُرفض هنا: «الدفعة … استلمها الوكيل مباشرة — راجعها من طابور تحصيلات الوكلاء».

### 3أ) تحصيل الدفع عند الاستلام بعد الشحن (تصحيح الشركة)

- بعد شحن طلب الوكيل (أو تسليمه عند الاستلام) **لا يستطيع الوكيل** الإبلاغ عن تحصيل الدفع عند الاستلام أو تغيير إبلاغه — أي تغيير بعد بدء التنفيذ **تصحيح** خاص بالشركة.
- المالية تسجّله: صفحة الطلب الداخلية ← **«إبلاغ دفع العميل»** (المبلغ، الوجهة، التاريخ، المرجع، الإثبات) — يتطلب صلاحية **إدارة الطلبات** أو **تأكيد المقبوضات** ويُسجَّل في السجل كتصحيح.
- بعدها يُتحقق منه كالمعتاد (القسم 3، أو طابور تحصيلات الوكلاء إن كان المال لدى الوكيل).

### 4) التسوية وحصة رسوم المزوّد

التسوية كالمعتاد ([المالية — 1ب](../roles/finance.md)): الوسيط ← البنك مع الرسوم. الدفعة قد تجمع وكلاء مختلفين؛ كل سطر يحتفظ بوكيله.

- **حصة الرسوم** = رسوم التسوية × مبلغ السطر ÷ إجمالي التسوية (بعملة الدفعة، دون فروق صرف).
- إن كان الوكيل يتحملها: «رسم مزوّد الدفع» مدين في كشفه، وقيد: مدين مستحقات الوكلاء / دائن رسوم بوابات الدفع.
- مثال: تسوية 2,000 (دفعة وكيل أ 1,000 + دفعة وكيل ب 1,000) برسوم 40 ← حصة كل وكيل **20**.
- عكس التسوية يعيد الحصة (تسوية دائنة بنفس القيد الأصلي معكوساً).

### 5) طابور تحصيلات الوكلاء (الدفع للوكيل مباشرة)

1. **الوكلاء ← تحصيلات الوكلاء** — «مدفوعات دفعها العملاء للوكيل مباشرة… لا تتحرك نقدية للشركة.» فلاتر: **الوكيل**، **الحالة** (بانتظار المراجعة…).
2. راجع **الإثبات** والمبلغ والمرجع.
3. **تحقق** ← «يؤكد أن الوكيل استلم {المبلغ}. يُسجل سطرًا للعلم…» ← «تم التحقق من التحصيل». أو **رفض** + **السبب (مطلوب)** ← «تم رفض التحصيل» (يُعاد احتساب الدفع المُبلَّغ للطلب).

- النتيجة: سطر **«حصّله الوكيل» للعلم** في الكشف — لا قيد نقدية ولا دائن للوكيل.

(صورة: طابور تحصيلات الوكلاء — تحقق)

### 6) مراحل الدفع وقاعدة الإتاحة

على صفحة طلب الوكيل (بطاقة **مراحل الدفع**) لكل دفعة:
**مُبلَّغ ← تم التحقق ← لدى مزوّد الدفع ← تمت التسوية ← بانتظار الاستحقاق ← متاح للصرف ← تم صرفه** (أو «حصّله الوكيل» / «مرفوض» / «معكوس»).

يصبح التحصيل **متاحاً للصرف** عندما تجتمع الثلاثة:

1. المال **مستلم** (طريقة لا تتطلب مطابقة، أو تسوية كاملة لدى المزوّد)،
2. **حدث استحقاق العمولة** للطلب وقع،
3. **مدة حجز الصرف** انقضت من آخر التاريخين.

**المتاح** = التحصيلات المتاحة − كل القيود المدينة الأخرى (بما فيها الصرف)، ولا يقل عن 0. وجود طلب أو إبلاغ لا يجعل شيئاً متاحاً.

### 7) الصرف للوكيل

1. تبويب **المدفوعات للوكيل** ← **صرف جديد** ← «صرف جديد — {الوكيل}».
2. راجع **مركز الصرف**: الرصيد، **المتاح**، قيد الانتظار، الخصومات، المصروف، «رصيد سالب مُرحّل» إن وُجد؛ و**الأرصدة المستحقة** (القيود المتاحة الأقدم أولاً).
3. أدخل **المبلغ** (بحد أقصى المتاح — صرف جزئي مسموح)، **حساب الصرف**، **تاريخ الصرف**، **المرجع** (التحويل / الشيك)، الإثبات، الملاحظات.
4. **تأكيد الصرف** ← «تم تسجيل الصرف {الرقم}». القيد: مدين مستحقات الوكلاء / دائن حساب الصرف؛ وفي الكشف «صرف» مدين.

- لا صرف مزدوج: الوكيل يُقفل أثناء الإنشاء، والطلب المكرر لا يُنشئ صرفاً ثانياً.
- **عكس** ← **السبب (مطلوب)** ← «تم عكس الصرف» — قيد عكسي و«عكس صرف» دائن يعيد المبلغ للرصيد.
- مدير الوكيل يرى الصرف والإثبات فقط.

(صورة: نافذة صرف جديد — مركز الصرف والأرصدة المستحقة)

### 8) الاسترداد للعميل والتسوية اليدوية

**تسجيل استرداد للعميل** (من صفحة طلب الوكيل أو قائمة الصف في تبويب **الطلبات**، `agents.finance.adjust`):

| **أعاد المبلغ**                      | الأثر                                                          |
| ------------------------------------ | -------------------------------------------------------------- |
| **الشركة (من حسابنا)** + **صُرف من** | «مبلغ مسترد لعميل» مدين على الوكيل + قيد استرداد من حساب الصرف |
| **الوكيل (مباشرة — للعلم فقط)**      | سطر للعلم، بلا حركة نقدية للشركة                               |

- المبلغ لا يتجاوز ما حصّلته تلك الجهة على الطلب. استرداد الشركة يتطلب ضبط حسابات الوكلاء.

**تسوية** (تبويب **كشف الحساب** ← **تسوية**): **الاتجاه** (دائن — زيادة ما نستحقه للوكيل / مدين — إنقاص)، **المبلغ**، **تاريخ القيد**، **السبب** ← **متابعة** ← تأكيد ← **تسجيل التسوية**. لا تُعدَّل بعد التسجيل؛ تُرحَّل مقابل «إيراد خدمات التنفيذ».

### 9) الترحيلات المعلقة حتى ضبط حسابات الوكلاء (D1)

1. **المالية ← الإعداد والفترات ← إعدادات الحسابات** ← قسم **«الوكلاء (القرار D1)»**: **مستحقات الوكلاء (التزام)**، **إيراد عمولات الوكلاء**، **إيراد خدمات التنفيذ**.
2. إلى أن تُضبط: قيود الرسوم تُسجَّل في الكشف بحالة **«بانتظار الحسابات»**، ويُمنع التحقق من تحصيلات حساب الشركة لطلبات الوكلاء، والصرف والاسترداد — لا يُرحَّل شيء إلى حسابات مُخمَّنة.
3. بعد الضبط يظهر في مساحة الوكيل: «{N} قيدًا في كشف الوكلاء بانتظار الترحيل» ← **ترحيل القيود المعلقة** (`agents.finance.post`) ← «تم ترحيل القيود المعلقة».

- بعد أول ترحيل تُقفل الحسابات الثلاثة، ويجب أن تكون بلا قيد عملة أو بعملة EGP.

### 10) الكشف — طباعة وتصدير

1. تبويب **كشف الحساب** ← **الفترة** (أيام تقويمية كتقارير المحاسبة).
2. الملخص: المبيعات دون الشحن، رسوم الشحن على العملاء، رسوم الخدمة، إجمالي قيمة الطلبات، الخصومات، الضريبة، المرتجعات، المستردات، أساس ونسبة العمولة، الخصومات بأنواعها، حصّلته الشركة / حصّله الوكيل (للعلم)، الموقف.
3. **قيود الكشف**: التاريخ، النوع، المرجع (رابط)، البيان، مدين، دائن، الرصيد، **الترحيل** (للعلم / بانتظار الحسابات / مُرحّل) ورابط **قيد اليومية**.
4. **طباعة الكشف** (`agents.statement.print` — A4 عرضي بالشعار وتاريخ الطباعة وأرقام الصفحات) أو التصدير من خيارات الجدول.

## مثال شامل (EGP) — من الطلب إلى الكشف المطابق

الاتفاقية كما في المهمة 1 (10%، شحن للشركة، شحن 30، مرتجع 25، خدمة 0، حجز 7 أيام) — قيم اتفاقية مثال للتوضيح؛ كل وكيل يُحاسَب بما في اتفاقيته، ورسم المرتجع **25** هنا ليس قيمة افتراضية في النظام. طلب «السعر شامل الشحن» **1,000 شامل 100** (900 بضاعة)، دفعه العميل إلى **حساب الشركة** بطريقة لا تتطلب مطابقة.

| #   | الحدث                           | سطر الكشف             | مدين  | دائن  | الرصيد   | القيد (GL)                                                                                |
| --- | ------------------------------- | --------------------- | ----- | ----- | -------- | ----------------------------------------------------------------------------------------- |
| 1   | تم الشحن                        | رسم شحن               | 30    |       | −30      | مدين مستحقات الوكلاء / دائن إيراد خدمات التنفيذ                                           |
| 2   | تأكيد وترحيل 1,000              | تحصيل مستلم           |       | 1,000 | 970      | مدين وسيط الطريقة / دائن مستحقات الوكلاء                                                  |
| 3   | تم التسليم                      | عمولة 10% × 900       | 90    |       | 880      | مدين مستحقات الوكلاء / دائن إيراد عمولات الوكلاء                                          |
| 3   | تم التسليم                      | شحن عميل محتجز        | 100   |       | **780**  | مدين مستحقات الوكلاء / دائن إيراد خدمات التنفيذ                                           |
| 4   | بعد 7 أيام من التسليم           | المتاح = 1,000 − 220  |       |       | متاح 780 | —                                                                                         |
| 5   | صرف جزئي 500                    | صرف                   | 500   |       | 280      | مدين مستحقات الوكلاء / دائن البنك                                                         |
| 6   | استلام مرتجع كامل (عكس العمولة) | عكس عمولة / رسم مرتجع | 25    | 90    | 345      | مدين إيراد العمولات / دائن المستحقات (90)؛ مدين المستحقات / دائن إيراد خدمات التنفيذ (25) |
| 7   | الشركة ردّت 1,000 للعميل        | مبلغ مسترد لعميل      | 1,000 |       | **−655** | مدين مستحقات الوكلاء / دائن حساب الصرف                                                    |

- **التحقق:** 1,000 − 90 − 100 − 30 = **780**؛ بعد الصرف 280؛ 280 + 90 − 25 = 345؛ 345 − 1,000 = **−655** (الوكيل مدين لنا).
- الشحن المحتجز (100) لا يُعكس عند المرتجع. الرصيد السالب يُرحَّل ويُخصم من تحصيلات لاحقة (D5)؛ لا استرداد تلقائي من الوكيل.
- رصيد «مستحقات الوكلاء» للشريك في دفتر الأستاذ = رصيد الكشف بعد ترحيل كل القيود.

## قرارات مفتوحة (افتراضات مطبّقة — بانتظار تأكيد المالك)

| #   | القرار                                                      | المطبّق الآن                                                               |
| --- | ----------------------------------------------------------- | -------------------------------------------------------------------------- |
| D1  | حسابات مستحقات الوكلاء وإيراد العمولات وإيراد خدمات التنفيذ | حقول في إعدادات الحسابات؛ الإنتاج «بانتظار الحسابات» حتى يسمّيها المالك    |
| D2  | الضريبة على بضاعة الوكيل وعلى عمولتنا ورسومنا               | لا ضريبة مخرجات على بضاعة الوكيل؛ لا ضريبة محسوبة على العمولة/الرسوم       |
| D3  | شروط كل وكيل                                                | حقول اتفاقية صريحة، بلا افتراضي                                            |
| D4  | منتج بعدة ملاك / طلب مختلط                                  | غير مدعوم: مالك واحد لكل منتج ولكل طلب                                     |
| D5  | رصيد سالب بعد الصرف                                         | يُرحَّل ويُخصم لاحقاً؛ سداد الوكيل النقدي يحتاج حساباً مقابلاً (غير منفّذ) |
| D6  | طلب بعملة غير عملة الاتفاقية                                | مرفوض                                                                      |

ملاحظات مالية أخرى بانتظار التأكيد: الشحن المحتجز لا يُعكس عند المرتجع · مرتجع قبل الاستحقاق يُستبعد من أساس العمولة · قيدا رسوم خدمة منفصلان · عمولة «تحقق المالية» لا تُعكس تلقائياً عند الإلغاء · رسم المرتجع مرة لكل شحنة · وكلاء بعملة غير EGP: كل قيد بسعره، ولا فروق صرف محققة عند الصرف.
