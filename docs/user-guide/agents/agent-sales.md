# مبيعات الوكيل (Agent Sales)

دليل مستخدم المبيعات في **بوابة الوكيل**: تسجّل العملاء المحتملين، وتحوّلهم إلى طلبات أو تنشئ طلباً مباشراً، وتُبلغ عن دفع العميل مع الإثبات، وتتابع التنفيذ. الشحن والتحقق من الدفع تنفّذهما الشركة.

## المهام

### 1) تسجيل عميل محتمل

1. **العملاء المحتملون** ← **عميل محتمل جديد**.
2. أدخل **اسم العميل**، **الجوال**، **الدولة**، **المدينة**، **العنوان**، **المنتج**، **الكمية**، و**طريقة التنفيذ** (تُستخدم افتراضياً عند التحويل).
3. احفظ ← «تم إنشاء العميل المحتمل {الرقم}.»

- «يبقى العميل المحتمل داخل وكالتك — لا يُوزَّع على موظفي الشركة.» فحص التكرار داخل وكالتك فقط.
- المنتجات المتاحة لك هي منتجات وكالتك فقط.
- إن ظهرت «لا توجد دول نشطة متاحة — تواصل مع الشركة.» فاطلب من الشركة تفعيل الدول.

(صورة: نموذج عميل محتمل جديد)

### 2) تحويل العميل المحتمل إلى طلب

1. افتح العميل المحتمل ← **تحويل إلى طلب**.
2. يُفتح نموذج «تحويل العميل المحتمل {الرقم} إلى طلب» ببيانات العميل والمنتج جاهزة. أكمل كما في المهمة 3 ← **تحويل إلى طلب**.
3. يظهر على العميل المحتمل: «تم تحويله إلى الطلب {الرقم}».

- لا يمكن تحويل عميل محتمل **مفقود** أو **غير مؤهَّل**.

### 3) إنشاء طلب جديد — اختيار طريقة التسعير

1. **الطلبات** ← **طلب جديد** (أو من **لوحة الوكيل**).
2. **العميل:** اسم العميل، الجوال، الدولة، المدينة، العنوان.
3. **التنفيذ والدفع:** **طريقة التنفيذ** (شحن / استلام) و**نوع الدفع** (مدفوع مسبقاً / الدفع عند الاستلام).
4. **المنتجات:** **إضافة منتج** ← **المنتج** و**الكمية** (يظهر «سعر القائمة» و«المتاح»).
5. **التسعير** — اختر إحدى الطريقتين:

| الطريقة              | ماذا تُدخل                                             | المثال                                           |
| -------------------- | ------------------------------------------------------ | ------------------------------------------------ |
| **الشحن يُضاف**      | **مبلغ السطر** لكل منتج؛ الشحن يُضاف فوقه              | 1,000 منتجات + 100 شحن = **1,100** يدفعها العميل |
| **السعر شامل الشحن** | **الإجمالي المتفق عليه شاملاً الشحن**؛ الشحن يُخصم منه | 1,000 شامل 100 شحن = **900** منتجات + 100 شحن    |

6. **تفصيل السعر** يتحدث مباشرة قبل الحفظ («جارٍ مراجعة الأسعار…»): المنتجات، الخصم، الضريبة، الشحن (مع **السعر المعتمد** — سعر المدينة أو سعر الدولة)، رسوم الخدمة، **الإجمالي المستحق**، وسطر شرح مثل:
   - الشحن يُضاف: «1,000 منتجات + 100 شحن = 1,100».
   - السعر شامل الشحن: «1,000 شامل 100 شحن = 900 منتجات + 100 شحن».
7. رسوم خدمة متفق عليها مع العميل؟ **إضافة رسوم خدمة** ← **رسوم الخدمة** (منفصلة عن الشحن).
8. **إنشاء الطلب** ← «تم إنشاء الطلب {الرقم}.» وللمدفوع مسبقاً: «الطلبات المدفوعة مسبقاً تُشحن بعد الإبلاغ عن الدفع.»

**عدة منتجات مع «السعر شامل الشحن»:** يُوزَّع مبلغ المنتجات على الأسطر بنسبة مبالغها (أو سعر القائمة × الكمية)، مقرّباً إلى 0.01 بحيث يساوي المجموع المبلغ تماماً. مثال: 1,000 شامل 100 على ثلاثة أسطر متساوية ← 900 = **300.00 + 300.00 + 300.00**؛ و1,100 شامل 100 ← 1,000 = **333.34 + 333.33 + 333.33**.

**لا يُضاف الشحن مرتين أبداً، ولا يُخمَّن ولا يُصفَّر.**

(صورة: طلب جديد — «الشحن يُضاف» وتفصيل السعر 1,000 + 100 = 1,100)
(صورة: طلب جديد — «السعر شامل الشحن» وتفصيل السعر 900 + 100 = 1,000)

### 4) قواعد رسوم الشحن والتعديل اليدوي

| الحالة                                         | ما يحدث                                                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| شحن إلى وجهة لها سعر في الاتفاقية              | يُستخدم **السعر المعتمد** تلقائياً (سعر المدينة يتقدم على سعر الدولة)                                              |
| تريد مبلغاً مختلفاً                            | **رسوم شحن مختلفة** ← **رسوم الشحن** + **سبب التعديل** (مطلوب) — يحتاج صلاحية «تعديل رسوم الشحن» ويُسجَّل للمراجعة |
| لا يوجد سعر ولا تملك صلاحية التعديل            | **لا يمكن حفظ الطلب** — اطلب من الشركة إضافة سعر للوجهة                                                            |
| **استلام** من المقر، أو منتجات رقمية/خدمات فقط | الشحن = 0 («بدون شحن») ولا يُضاف أي شحن                                                                            |

- في «السعر شامل الشحن» يجب أن يكون الشحن + رسوم الخدمة **أقل** من الإجمالي، وكل المبالغ ≥ 0.

### 5) الإبلاغ عن دفع العميل (مع الإثبات)

1. افتح الطلب ← **الإبلاغ عن الدفع** ← نافذة **«إبلاغ دفع العميل»** — «هذا إبلاغ فقط — المالية تتحقق منه بشكل منفصل.»
2. **هل دفع العميل؟**
   - **لم يدفع بعد** ← «تم الحفظ: العميل لم يدفع بعد.»
   - **دفع كامل المبلغ** ← يُسجَّل كامل **المتبقي** من الإجمالي المستحق دون إدخال مبلغ.
   - **دفع جزئي** ← **المبلغ المدفوع** (ما دفعه فعلاً فقط؛ لا يتجاوز المتبقي).
3. **جهة الدفع** — «اختر أين دفع العميل»:

| الجهة           | معناها                                        | أثرها                                           |
| --------------- | --------------------------------------------- | ----------------------------------------------- |
| **حساب الشركة** | العميل حوّل إلى حساب تملكه الشركة             | بعد تحقق المالية يُضاف المبلغ لرصيد وكالتك      |
| **حساب الوكيل** | العميل دفع للوكالة مباشرة (إن سمحت الاتفاقية) | المالية تراجعه؛ سطر **مذكرة** فقط — المال عندكم |

4. **تاريخ الدفع** (ليس في المستقبل)، **مرجع الدفع**، و**إرفاق إيصال السداد** (JPG / PNG / WEBP / PDF).
5. راجع **الإجمالي المستحق** · **المُبلَّغ سابقاً** · **سيُبلَّغ عن** ← **حفظ الإبلاغ** ← «تم الإبلاغ عن الدفع — بانتظار تحقق المالية.»

**الإبلاغ ≠ التحقق:**

| الحالة على الطلب                                 | معناها                          |
| ------------------------------------------------ | ------------------------------- |
| **مدفوع (مُبلَّغ)** / **مدفوع جزئياً (مُبلَّغ)** | ما أبلغت به أنت                 |
| **بانتظار المالية**                              | لم تراجعه المالية بعد           |
| **تحققت المالية** / **طابقته المالية**           | المالية أكدت وصول المال         |
| **رفضته المالية** / **اعترضت عليه المالية**      | راجع **سبب المالية** على الدفعة |

**أثر الإبلاغ على الشحن:**

| الطلب                         | يُجهَّز للشحن؟                                             |
| ----------------------------- | ---------------------------------------------------------- |
| مدفوع مسبقاً + إبلاغ **كامل** | **نعم** — دون انتظار المالية                               |
| مدفوع مسبقاً + إبلاغ **جزئي** | **لا** — أكمل الإبلاغ عن باقي المبلغ                       |
| **الدفع عند الاستلام**        | نعم دون إبلاغ؛ المندوب يحصّل الإجمالي المستحق (شامل الشحن) |
| **استلام** مدفوع مسبقاً       | بعد إبلاغ كامل فقط                                         |

**بعد الشحن لا يمكنك تغيير الإبلاغ:** بمجرد شحن الطلب (أو تسليمه عند الاستلام) لا تستطيع مبيعات الوكيل أن تُبلغ عن تحصيل **الدفع عند الاستلام** أو تغيّر إبلاغاً سابقاً — أي تغيير بعدها **تصحيح** خاص بالشركة. أرسل للمالية ما حصّله المندوب (المبلغ والمرجع والإثبات)، وهي تسجّله من **«إبلاغ دفع العميل»** على صفحة الطلب الداخلية.

(صورة: نافذة «إبلاغ دفع العميل» — دفع جزئي إلى حساب الشركة مع الإثبات)

### 6) متابعة الطلب

1. **الطلبات** ← الفلاتر **الدفع المُبلَّغ** · **حالة المالية** · **التنفيذ** · **الطريقة**.
2. في الطلب: **تقدم التنفيذ** (تم إنشاء الطلب ← تم الشحن ← مكتمل)، الشحنات (**شركة الشحن**، **رقم التتبع**)، **الدفع** مع **المرحلة** لكل دفعة، **المرتجعات**، **السجل الزمني**.
3. لا يمكنك تغيير حالة الشحن ولا التحقق من الدفع — هذا عمل الشركة.

## مثال شامل (EGP)

1. عميل محتمل «منى» ← **تحويل إلى طلب** ← شحن إلى القاهرة، مدفوع مسبقاً، منتج واحد.
2. **السعر شامل الشحن**: الإجمالي المتفق عليه **1,000**؛ السعر المعتمد للقاهرة **100** ← تفصيل السعر: **900 منتجات + 100 شحن = 1,000**.
3. العميلة حوّلت **400** إلى **حساب الشركة** ← **دفع جزئي** 400 + إيصال ← «مدفوع جزئياً (مُبلَّغ)» — **لا يُشحن بعد**؛ المتبقي للإبلاغ **600**.
4. حوّلت الباقي ← **دفع كامل المبلغ** (يُسجَّل 600 تلقائياً) ← «مدفوع (مُبلَّغ)» — يصبح الطلب جاهزاً للشحن قبل تحقق المالية.
5. تتحقق المالية من الدفعتين (1,000)، ويشحن فريق الشركة ويسلّم.
6. في كشف وكالتك (عمولة 10%، شحن محتجز للشركة، رسم شحن 30): 1,000 − 90 − 100 − 30 = **780** مستحق لوكالتك.
7. لو أعادت العميلة الطلب كاملاً بعد التسليم: يُعكس 90 (عمولة) ويُخصم **رسم المرتجع** — **25** في هذا المثال.

الأرقام (10%، 30، 25) قيم اتفاقية **مثال** للتوضيح فقط — كل وكالة تُحاسَب بالرسوم المذكورة في اتفاقيتها.

لو اختارت الطريقة **الشحن يُضاف** بمنتجات 1,000: الإجمالي المستحق **1,100**، والعمولة 10% × 1,000 = 100، والرصيد 1,100 − 100 − 100 − 30 = **870**.

## أخطاء شائعة

| الرسالة / السلوك                            | المعالجة                                                  |
| ------------------------------------------- | --------------------------------------------------------- |
| «أدخل سبب تعديل الشحن.»                     | التعديل اليدوي يحتاج سبباً                                |
| لا يُحفظ طلب شحن لوجهة بلا سعر              | اطلب سعراً للوجهة من الشركة، أو صلاحية «تعديل رسوم الشحن» |
| «لا يمكن أن يتجاوز المبلغ المتبقي المستحق.» | أدخل المدفوع فعلاً فقط                                    |
| «لا توجد جهات دفع مُعدّة لوكالتك.»          | الشركة لم تضف وجهات دفع — تواصل معها                      |
| «لا يمكن أن يكون تاريخ الدفع في المستقبل.»  | صحّح التاريخ                                              |
| الطلب المدفوع مسبقاً لا يُشحن               | الإبلاغ جزئي أو غير موجود — أبلغ عن كامل المبلغ           |
| لا يمكن الإبلاغ بعد شحن الطلب               | تصحيح خاص بالشركة — أرسل التفاصيل للمالية لتسجّلها        |
| «لا توجد منتجات متاحة لك بعد.»              | لا منتجات مملوكة لوكالتك أو بلا مخزون — تواصل مع الشركة   |
