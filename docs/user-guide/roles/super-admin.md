# مدير النظام (Super Admin)

حساب التحقق: `qa-admin@oms.haseb.org` — صلاحيات كاملة (`isSuperAdmin` + كل الأذونات).

## التبويبات / القوائم المستخدمة

يرى كل وحدات الشريط الجانبي: CRM، مبيعات، شحن، مشتريات، منتجات ومخزون، موارد بشرية، مستثمرون، مصاريف، مالية، بيانات أساسية، إدارة بيانات، تقارير، إعدادات.

## مهام شائعة

### 1) التحقق من بيانات أساسية قبل البيع

1. افتح المنتجات وتأكد من وجود صنف نشط بمخزون افتتاحي إن لزم.
2. راجع المخزن (مثال الجولة: المخزن الرئيسي — مقر الدقي) والوحدة والفئة والعملة **EGP**.
3. راجع حساب الاستلام ومصدر الدفع ودفاتر اليومية عند الحاجة المالية.

سجلات DEMO: [PRD-2026-000017](https://oms.haseb.org/products/14743ed8-3e40-4063-915c-650ed8fc7612)، [PRD-2026-000018](https://oms.haseb.org/products/c36133d4-3310-4110-ab13-4701f47b4064).

### 2) إدارة المستخدمين والصلاحيات

1. الإعدادات → المستخدمون (`/settings/users`).
2. أنشئ أو عدّل مستخدماً وامنح الأذونات مباشرة من محرر المستخدم (لا توجد صفحة أدوار منفصلة).
3. لا تعتمد على صفحات الإعدادات الأخرى كوظائف جاهزة — معظمها **قشرة «قريباً»** (انظر أدناه).

### 3) مراجعة مسار متجر كامل (مرجع DEMO)

1. عميل محتمل → طلب متجر → تأكيد وترحيل الدفع → فاتورة.
2. مثال: [LD-2026-000073](https://oms.haseb.org/crm/leads/07b032ef-1e6e-48a9-a238-e343c02f8ce1) → [STO-2026-000083](https://oms.haseb.org/store-orders/e5cf5e89-c276-49b4-9f13-ce969fa6cafa) (900 EGP، مدفوع بالكامل، جاهز للشحن ولم يُشحن بعد في سيناريو الجولة).

### 4) مراجعة التقارير المالية بعد العمليات

1. التقارير → المالية.
2. ميّز ميزان المراجعة وقائمة الدخل والميزانية والتدفق النقدي وكشوف الشركاء (موثّق في F7).

## الدفع مقابل الشحن

لا تربط حالة الدفع بحالة الشحن. طلب مدفوع بالكامل يمكن أن يبقى غير مشحون. راجع [workflows.md](../workflows.md).
