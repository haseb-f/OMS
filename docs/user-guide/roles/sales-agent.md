# مندوب المبيعات (Sales Agent)

حساب التحقق: `qa-sales-agent@oms.haseb.org`

صلاحيات السكربت: CRM (عرض/إنشاء/تعديل/تحويل عملاء محتملين)، مبيعات (عروض/أوامر/فواتير عرض وإنشاء وتعديل)، طلبات متجر (عرض/إنشاء/تعديل)، منتجات (عرض/إنشاء/تعديل)، إنشاء شركاء، بحث عالمي عن عملاء/أوامر.

**ليس لديه** مقارنة بمدير المبيعات: `crm.leads.manage` / `crm.leads.archive`، مركز الاستيراد.

## التبويبات المستخدمة

- CRM: العملاء المحتملون، القمع (إن ظهر)
- المبيعات: العملاء، عروض الأسعار، أوامر البيع، طلبات المتجر، الفواتير، المرتجعات (حسب ظهور القائمة)
- المنتجات

لا يظهر له عادةً: مكتب الشحن التشغيلي، المالية العميقة، المستخدمون — إلا بصلاحيات إضافية.

## مهام شائعة

### 1) تسجيل عميل محتمل وتحويله لطلب متجر

1. CRM → العملاء المحتملون → جديد.
2. أدخل الاسم وبيانات التواصل والمبلغ المتفق عليه (**أكبر من صفر**).
3. حوّل إلى طلب متجر بعد الاتفاق.
4. تحقق من رقم الطلب (مثال: LD-2026-000073 → STO-2026-000083 بمبلغ 900 EGP).

> ملاحظة: إنشاء العميل المحتمل من الواجهة قد يتجمد أحياناً — انظر [issues.md](../issues.md). مسار API في الجولة نجح.

### 2) متابعة طلب متجر

1. المبيعات → طلبات المتجر → افتح الطلب.
2. راجع الإجمالي والعملة (EGP) وحالة الدفع.
3. سجّل بيانات الدفع؛ التأكيد والترحيل للمخوّل إن لم تكن لديك صلاحية Confirm.

### 3) مسار B2B: عرض → أمر → فاتورة

1. أنشئ عرض سعر بكميات موجبة (الكمية 0 مرفوضة).
2. أكّد أمر البيع ثم الفاتورة.
3. مرجع: QT-2026-000014 → SO-2026-000012 → INV-2026-000060 (1500 EGP).

## المراحل ومن المسؤول

| المرحلة            | من                                                                      |
| ------------------ | ----------------------------------------------------------------------- |
| عميل محتمل         | المندوب                                                                 |
| التحويل لطلب       | المندوب (`crm.leads.convert`)                                           |
| تأكيد وترحيل الدفع | عادةً المالية                                                           |
| فاتورة طلب متجر    | يحتاج `store-orders.generate_invoice` (ليست في حزمة المندوب الافتراضية) |
| الشحن              | الشحن — مستقل                                                           |

## الدفع مقابل الشحن

الدفع المكتمل لا يعني الشحن. مثال: STO-2026-000083 مدفوع بالكامل وجاهز للشحن ولم يُشحن.

## أخطاء شائعة

| الحالة                                | ماذا تفعل                                      |
| ------------------------------------- | ---------------------------------------------- |
| تحويل بمبلغ 0.00                      | أدخل مبلغاً > 0 — يبقى عميلاً محتملاً          |
| كمية صفر في البنود                    | أدخل كمية موجبة                                |
| دفعة على طلب مسدَّد                   | النظام يرفض                                    |
| البحث عن دفعة مؤكدة في طابور المراجعة | الطابور لغير المؤكدة؛ راجع تبويب مدفوعات الطلب |

## تقارير ذات صلة

تقارير المبيعات/CRM في القائمة = **قشرة «قريباً»**. كشوف العملاء تحتاج صلاحيات تقارير مالية عادةً.
