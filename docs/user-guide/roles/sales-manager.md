# مدير المبيعات (Sales Manager)

حساب التحقق: `qa-sales-manager@oms.haseb.org`

يشمل صلاحيات المندوب **إضافةً إلى**: `crm.leads.manage`، `crm.leads.archive`، ومركز الاستيراد (`import-center.view/manage/export`).

## التبويبات المستخدمة

- CRM: العملاء المحتملون، القمع، فرق المبيعات (إن ظهرت بصلاحية الفرق)
- المبيعات: العملاء، المجموعات، عروض/أوامر/طلبات متجر/استيراد/يحتاج مراجعة/فواتير/مرتجعات
- المنتجات
- إدارة البيانات → مركز الاستيراد

## مهام شائعة

### 1) الإشراف على العملاء المحتملين والتحويل

1. راجع قائمة العملاء المحتملين والقمع.
2. أرشِف أو أدِر الحالات غير الصالحة (صلاحية archive/manage).
3. راقب التحويلات ذات المبلغ الصحيح — التحويل بصفر مرفوض ويترك السجل غير محوَّل.

مرجع: [LD-2026-000073](https://oms.haseb.org/crm/leads/07b032ef-1e6e-48a9-a238-e343c02f8ce1) → STO-2026-000083.

### 2) استيراد طلبات / بيانات عبر مركز الاستيراد

1. إدارة البيانات → مركز الاستيراد.
2. نفّذ الاستيراد وفق القوالب المعتمدة في النظام.
3. راجع طلبات المتجر → يحتاج مراجعة عند ظهور سجلات معلّقة.

> منطق الاستيراد التفصيلي **لم يُمرَّر كفحوصات بيانات** في DEMO-GUIDE-20260924 (الصفحة تُحمَّل في مسح المتصفح فقط).

### 3) مسار متجر حتى الفاتورة (بالتنسيق مع المالية)

1. تأكد من بيانات الطلب والمبلغ.
2. بعد تسجيل الدفع: تأكيد وترحيل (idempotent).
3. إصدار الفاتورة مرة واحدة — إعادة التوليد تُرفض إن وُجدت فاتورة.

مرجع: STO-2026-000083 / INV-2026-000057 / JV-2026-000235 + JV-2026-000236.

### 4) مسار B2B ومتابعة التحصيل

1. عرض → أمر → فاتورة (1500 EGP في DEMO).
2. التحصيل الجزئي ثم الكامل مسؤولية المالية عادةً؛ المدير يتابع حالة الفاتورة مع العميل.

## المراحل ومن المسؤول

| المرحلة                   | من                                  |
| ------------------------- | ----------------------------------- |
| توزيع/إدارة عملاء محتملين | مدير المبيعات                       |
| تحويل وبيع                | مندوب / مدير                        |
| تأكيد دفعات وقبض          | مالية                               |
| شحن                       | شحن                                 |
| مرتجع بعد التسليم         | مبيعات + مخزون/مالية للأثر المحاسبي |

## الدفع مقابل الشحن

لا تربط إغلاق البيع بشحن الناقل. الطلب المدفوع قد يبقى في مكتب الشحن. راجع STO-2026-000083 مقابل STO-2026-000084 (تم التسليم لاحقاً في F2).

## أخطاء شائعة

- نفس أخطاء المندوب (مبلغ صفر، كمية صفر، دفعة مكررة على مسدَّد).
- مرتجع بكمية أكبر من القابل للإرجاع → مرفوض (موثّق في F2).
- استرداد نقدي للعميل بعد المرتجع: **لا يوجد API استرداد عميل** في الجولة — يبقى رصيد دائن للعميل (مثال 450 بعد SR-2026-000015).

## تقارير ذات صلة

- تقارير المالية إن مُنحت صلاحية (ليست في حزمة المدير الافتراضية في سكربت QA).
- `/reports/sales` و `/reports/crm` = **قشرة**.
