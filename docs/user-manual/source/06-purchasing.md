# المشتريات

دورة الشراء في النظام: **المورد** ← **أمر الشراء** (اتفاق فقط) ← **فاتورة الشراء** (استلام البضاعة وتسجيل التكلفة) ← **دفع المورد**.

## الموردون

**أين تذهب:** **المشتريات** ← **الموردون**.
**الصلاحية:** الشركاء ← عرض وإنشاء.

- أضف المورد بالاسم (*) ورقم الهاتف والدولة والمدينة والعنوان والعملة.
- لا يُحذف المورد نهائيًا؛ يُؤرشف ويمكن إعادة تفعيله.

## أوامر الشراء

**أين تذهب:** **المشتريات** ← **أوامر الشراء**.
**الصلاحية:** أوامر الشراء ← عرض، إنشاء، اعتماد.

![قائمة أوامر الشراء](06-01-po-list)

- [1] **أمر شراء جديد**.
- [2] **الحالة**: **مسودة** ← **معتمد** ← **مغلق**، ويمكن **الإلغاء** من المسودة أو المعتمد.

> [!note] أمر الشراء اتفاق فقط
> أمر الشراء لا يُدخل مخزونًا ولا يغيّر تكلفة المنتج ولا يُنشئ قيدًا محاسبيًا ولا دفعة، حتى بعد اعتماده. البضاعة والتكلفة تدخلان النظام فقط مع **فاتورة الشراء**.

### إنشاء أمر شراء واعتماده

1. اضغط **أمر شراء جديد**.
2. اختر **المورد** (*). تاريخ المستند والعملة يُملآن تلقائيًا.
3. في **بنود المنتجات** اختر المنتج والكمية وسعر الوحدة. يحسب النظام إجمالي السطر والإجمالي الكلي. يمكنك **استعراض المنتجات** لاختيار عدة منتجات.
4. اضغط **حفظ**. **النتيجة:** أمر شراء برقم مثل `PO-2026-000002` بحالة **مسودة**.
5. اضغط **اعتماد** ليصبح **معتمد**.

![أمر شراء بحالة مسودة](06-02-po-detail)

- [1] الحالة **مسودة**.
- [2] زر **اعتماد**.
- [3] **المزيد**: **تكرار** أو **إلغاء**.
- [4] **بنود المنتجات**.

### استلام البضاعة: تحويل أمر الشراء إلى فاتورة

1. افتح أمر الشراء **المعتمد**.
2. اضغط **تحويل إلى فاتورة**. تظهر نافذة «استلام البضاعة — تحويل إلى فاتورة».
3. اختر **مستودع الاستلام** ثم **تحويل إلى فاتورة**. يُستلَم كل بند بكميته المطلوبة بالكامل.
4. **النتيجة:** فاتورة شراء جديدة بحالة **مسودة**، ويصبح أمر الشراء **مغلق** بعد تحويله بالكامل.

## فواتير الشراء

**أين تذهب:** **المشتريات** ← **فواتير الشراء**.

![فاتورة شراء مؤكدة](06-03-pi-detail)

- [1] رقم الفاتورة وحالتها وحالة الدفع.
- [2] **المستودع** الذي تدخل إليه كل كمية.

**تأكيد الفاتورة:** **إرسال للاعتماد** ← **اعتماد** ← **تأكيد** (حسب صلاحياتك). عند **التأكيد**:

- تدخل الكميات المخزون (حركة استلام مشتريات).
- تُحدَّث **تكلفة المنتج** بطريقة متوسط التكلفة.
- يُرحَّل قيد: من ح/ المخزون إلى ح/ الموردين.

بعد التأكيد يمكنك **تسجيل دفعة** للمورد أو **إنشاء مرتجع** من نفس الصفحة.

## مدفوعات الموردين والمرتجعات والتكاليف المرحلة

- **مدفوعات الموردين** (**المالية** ← **مدفوعات الموردين**): سند صرف للمورد يُخصَّص على فاتورة أو أكثر. حالة دفع الفاتورة تتحدث تلقائيًا (غير مدفوعة / مدفوعة جزئيًا / مدفوعة).
- **مرتجعات الشراء** (**المشتريات** ← **المرتجعات**): ترجع الكمية للمورد وتعكس المبالغ.
- **التكاليف المرحلة** (**المشتريات** ← **التكاليف المرحلة**): لتحميل تكاليف إضافية مثل الشحن الوارد والجمارك على المشتريات.
- **عروض الأسعار** (**المشتريات** ← **عروض الأسعار**): يمكن تحويل عرض سعر المورد إلى أمر شراء.
