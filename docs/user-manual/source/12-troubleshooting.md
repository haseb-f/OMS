# استكشاف الأخطاء الشائعة

| المشكلة                                                          | السبب المحتمل                                                                                      | الحل                                                                        |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| طُلب مني تسجيل الدخول فجأة                                       | انتهت الجلسة: ساعتان دون نشاط، أو 12 ساعة منذ الدخول، أو أُعيد تعيين كلمة مرورك، أو أغلقت المتصفح. | سجّل الدخول من جديد؛ ستعود لنفس الصفحة.                                     |
| بقيت مسجّلًا بعد إغلاق المتصفح                                   | المتصفح مضبوط على استعادة الجلسة السابقة.                                                          | استخدم **تسجيل الخروج** دائمًا على الأجهزة المشتركة.                        |
| لا أرى وحدة أو زرًا مذكورًا في الدليل                            | لا تملك الصلاحية.                                                                                  | اطلبها من مدير النظام (الفصل 8).                                            |
| ظهرت رسالة «لا توجد صلاحية» عند فتح صفحة                         | الصفحة تحتاج صلاحية إضافية، مثل **مركز الاستيراد** لصفحات الاستيراد.                               | اطلب الصلاحية المحددة.                                                      |
| لا أستطيع تغيير شركة الشحن أو رقم التتبع                         | لا تملك **تعيين شركة الشحن ورقم الشحنة**.                                                          | اطلبها، أو اترك التعيين لمسؤول الشحن.                                       |
| رسالة «هذا العميل موجود بالفعل»                                  | رقم الهاتف مسجل لعميل لديك.                                                                        | اختر **إنشاء طلب جديد لنفس العميل** أو **إلغاء وعدم التكرار**.              |
| «اختر طريقة التعامل مع العميل المسجل قبل الحفظ»                  | ظهر تحذير العميل الموجود ولم تختر قرارًا.                                                          | اختر أحد الزرين في التحذير.                                                 |
| البحث المتقدم لا يعرض نتائج بالاسم                               | البحث بالاسم يحتاج الاسم الأول والأخير، ولا يعرض شيئًا إذا تطابق أكثر من 5 عملاء.                  | ابحث برقم الهاتف أو رقم الطلب.                                              |
| «عدد مرات البحث كبير»                                            | تجاوزت 15 بحثًا في 10 دقائق أو 100 في اليوم.                                                       | انتظر بضع دقائق.                                                            |
| طلب مُسلَّم يظهر **فشل الإثبات**                                 | منتج بلا تكلفة، رصيد غير كافٍ، مستودع غير محدد، حساب ناقص، أو منتج غير نشط.                        | عالج السبب المذكور في التنبيه الأحمر ثم **إعادة محاولة الإثبات** (الفصل 5). |
| «إعادة محاولة الإثبات» مرفوضة                                    | الطلب لم يُسلَّم بعد.                                                                              | سجّل التسليم أولًا.                                                         |
| المتاح أقل من الرصيد الفعلي                                      | كميات محجوزة لطلبات مشحونة لم تُسلَّم.                                                             | طبيعي؛ يزول الحجز عند التسليم أو فشله.                                      |
| لا يمكن ترحيل أي مستند: «السنة المالية ليس لها رصيد افتتاحي بعد» | لم يُدخل الرصيد الافتتاحي للسنة.                                                                   | أدخله من **المالية** ← **الأرصدة الافتتاحية**.                              |
| إقفال فترة الشركاء مرفوض                                         | حسابا الشركاء غير محددين، أو الفترة ليست شهرًا/ربعًا/سنة كاملة، أو مقفلة من قبل.                   | حدّد الحسابين في **إعدادات الحسابات** واختر فترة صحيحة.                     |
| مجموع نسب الشركاء يتجاوز 100%                                    | اتفاقيات سارية متداخلة.                                                                            | أنهِ اتفاقية أو عدّل النسب بزر **تغيير النسبة**.                            |
| زر **التالي** أو **حفظ** لا يعمل                                 | حقل مطلوب (*) فارغ أو قيمة غير صحيحة.                                                              | ابحث عن الحقل ذي الإطار الأحمر والرسالة تحته.                               |
| رقم الهاتف لا يُقبل                                              | الرقم غير صحيح لدولة رمز الاتصال المختار.                                                          | اختر رمز الدولة الصحيح ثم اكتب الرقم المحلي.                                |
| تغيّرت صلاحياتي ولم تظهر بعد                                     | التحديث يصل للجلسات المفتوحة خلال دقيقة على الأكثر.                                                | أعد تحميل الصفحة بعد دقيقة.                                                 |

## قبل التواصل مع الدعم

جهّز المعلومات التالية: اسم الصفحة، رقم المستند (مثل `STO-2026-000003`)، نص الرسالة كما ظهرت، والوقت التقريبي. لا ترسل كلمة المرور لأي أحد، ولا حتى للدعم.
