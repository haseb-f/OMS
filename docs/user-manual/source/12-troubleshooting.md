# استكشاف الأخطاء الشائعة

| المشكلة                                                          | السبب المحتمل                                                                                                                                                        | الحل                                                                                               |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| طُلب مني تسجيل الدخول فجأة                                       | انتهت الجلسة: ساعتان دون نشاط، أو 12 ساعة منذ الدخول، أو أُعيد تعيين كلمة مرورك، أو أغلقت المتصفح.                                                                   | سجّل الدخول من جديد؛ ستعود لنفس الصفحة.                                                            |
| بقيت مسجّلًا بعد إغلاق المتصفح                                   | المتصفح مضبوط على استعادة الجلسة السابقة.                                                                                                                            | استخدم **تسجيل الخروج** دائمًا على الأجهزة المشتركة.                                               |
| لا أرى وحدة أو زرًا مذكورًا في الدليل                            | لا تملك الصلاحية.                                                                                                                                                    | اطلبها من مدير النظام (الفصل 8).                                                                   |
| لا أرى «استيراد الشحن» في القائمة                                | الصفحة تحتاج صلاحية **مركز الاستيراد** إضافة إلى صلاحيات الشحن.                                                                                                      | اطلب صلاحية مركز الاستيراد.                                                                        |
| ظهرت رسالة «لا توجد صلاحية» عند فتح صفحة                         | الصفحة أو الإجراء يحتاج صلاحية لا تملكها.                                                                                                                            | اطلب الصلاحية المحددة من مدير النظام.                                                              |
| لا أستطيع تغيير شركة الشحن أو رقم التتبع                         | لا تملك **تعيين شركة الشحن ورقم الشحنة**.                                                                                                                            | اطلبها، أو اترك التعيين لمسؤول الشحن.                                                              |
| رسالة «هذا العميل موجود بالفعل»                                  | رقم الهاتف مسجل لعميل لديك.                                                                                                                                          | اختر **إنشاء طلب جديد لنفس العميل** أو **إلغاء وعدم التكرار**.                                     |
| «اختر طريقة التعامل مع العميل المسجل قبل الحفظ»                  | ظهر تحذير العميل الموجود ولم تختر قرارًا.                                                                                                                            | اختر أحد الزرين في التحذير.                                                                        |
| البحث المتقدم لا يعرض نتائج بالاسم                               | البحث بالاسم يحتاج الاسم الأول والأخير، ولا يعرض شيئًا إذا تطابق أكثر من 5 عملاء.                                                                                    | ابحث برقم الهاتف أو رقم الطلب.                                                                     |
| «عدد مرات البحث كبير»                                            | تجاوزت 15 بحثًا في 10 دقائق أو 100 في اليوم.                                                                                                                         | انتظر بضع دقائق.                                                                                   |
| طلب مُسلَّم يظهر **فشل الإثبات**                                 | منتج بلا تكلفة، رصيد غير كافٍ، مستودع غير محدد، حساب ناقص، أو منتج غير نشط.                                                                                          | عالج السبب المذكور في التنبيه الأحمر ثم **إعادة محاولة الإثبات** (الفصل 5).                        |
| «إعادة محاولة الإثبات» مرفوضة                                    | الطلب لم يُسلَّم بعد.                                                                                                                                                | سجّل التسليم أولًا.                                                                                |
| المتاح أقل من الرصيد الفعلي                                      | كميات محجوزة لطلبات أُنشئت ولم تُشحن بعد.                                                                                                                            | طبيعي؛ يزول الحجز عند الشحن أو إلغاء الطلب.                                                        |
| الطلب «ناقص» ولا يُشحن                                           | لم يكفِ المتاح لحجز بند عند الإنشاء؛ الشحن يُرفض لأن البند غير محجوز.                                                                                                | أدخل المخزون (فاتورة شراء أو تسوية) ثم **احجز الآن** في لوحة المخزون، أو اشحن البنود المحجوزة فقط. |
| طرد فشل تسليمه وما زال «في الطريق»                               | البضاعة لا تعود للمخزون تلقائيًا؛ ما زالت مع شركة الشحن.                                                                                                             | عند وصولها: **استلام البضاعة الراجعة** (سليم / تالف) — الفصل 4.                                    |
| أُكِّدت دفعة بالخطأ                                              | لا تُحذف الدفعات المؤكدة أبدًا.                                                                                                                                      | **عكس** الدفعة مع السبب من لوحة التحصيل — الفصل 7.                                                 |
| «لا يمكن رد … — المتاح للرد على الطلب … هو … فقط»                | المبلغ أكبر من **مستحق الرد** (ما حُصّل فعلًا بعد الإشعارات الدائنة).                                                                                                | سجّل الرد بالمبلغ المستحق فقط.                                                                     |
| صف في ملف الاستيراد «متجاوز — مستورد سابقًا»                     | نفس الصف استُورد من قبل؛ إعادة الاستيراد لا تُكرر الطلبات.                                                                                                           | لا شيء؛ للصف الجديد فعلًا غيّر رقم الطلب الخارجي.                                                  |
| صف استيراد «بانتظار المراجعة»                                    | رقم الهاتف لعميل موجود.                                                                                                                                              | **طلبات المتجر** ← **يحتاج مراجعة** ← **تأكيد** أو **رفض**.                                        |
| «هذا الجدول مربوط بواسطة مستخدم آخر» عند ربط Google Sheet        | الجدول ربطه مستخدم آخر، أو هو مصدر مزامنة مستمرة.                                                                                                                    | استخدم جدولًا خاصًا بك، أو اطلب من صاحبه الاستيراد.                                                |
| تعذّر قراءة Google Sheet                                         | الجدول غير مشارك مع عنوان النظام أو الرابط خاطئ.                                                                                                                     | شارك الجدول بصلاحية **عارض** مع العنوان الظاهر في المعالج، ثم أعد المحاولة.                        |
| طلب وكيل مرفوض: لا توجد اتفاقية شحن سارية                        | لا توجد اتفاقية شحن مفعّلة للوكيل في تاريخ الطلب، أو لا تغطي الخدمة والوجهة.                                                                                         | فعّل اتفاقية من **الوكلاء** ← الوكيل ← **الإعدادات** ← **اتفاقية الشحن** — الفصل 10.               |
| لا أرى أرقام زملائي أو ترتيبهم بالأسماء                          | الرؤية الافتراضية لأرقامك وترتيبك فقط.                                                                                                                               | طبيعي؛ الرؤية الشاملة بصلاحية **تقارير المبيعات ← عرض كل السجلات (كل الموظفين)**.                  |
| لا يمكن ترحيل أي مستند: «السنة المالية ليس لها رصيد افتتاحي بعد» | لم يُدخل الرصيد الافتتاحي للسنة.                                                                                                                                     | أدخله من **المالية** ← **الأرصدة الافتتاحية**.                                                     |
| إقفال فترة الشركاء مرفوض أو الزر معطّل                           | الفترة لم تنتهِ بعد (الإقفال متاح من اليوم التالي لآخر يوم فيها بتوقيت القاهرة)، أو حسابا الشركاء غير محددين، أو الفترة ليست شهرًا/ربعًا/سنة كاملة، أو مقفلة من قبل. | انتظر انتهاء الفترة (المعاينة وحفظ المراجعة متاحان قبلها)، وحدّد الحسابين في **إعدادات الحسابات**. |
| مجموع نسب الشركاء يتجاوز 100%                                    | اتفاقيات سارية متداخلة.                                                                                                                                              | أنهِ اتفاقية أو عدّل النسب بزر **تغيير النسبة**.                                                   |
| زر **التالي** أو **حفظ** لا يعمل                                 | حقل مطلوب (*) فارغ أو قيمة غير صحيحة.                                                                                                                                | ابحث عن الحقل ذي الإطار الأحمر والرسالة تحته.                                                      |
| رقم الهاتف لا يُقبل                                              | الرقم غير صحيح لدولة رمز الاتصال المختار.                                                                                                                            | اختر رمز الدولة الصحيح ثم اكتب الرقم المحلي.                                                       |
| تغيّرت صلاحياتي ولم تظهر بعد                                     | التحديث يصل للجلسات المفتوحة خلال دقيقة على الأكثر.                                                                                                                  | أعد تحميل الصفحة بعد دقيقة.                                                                        |

## قبل التواصل مع الدعم

جهّز المعلومات التالية: اسم الصفحة، رقم المستند (مثل `STO-2026-000003`)، نص الرسالة كما ظهرت، والوقت التقريبي. لا ترسل كلمة المرور لأي أحد، ولا حتى للدعم.
