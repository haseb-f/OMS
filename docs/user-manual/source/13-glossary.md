# مسرد المصطلحات

| المصطلح                 | التعريف                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------- |
| إثبات البيع             | إصدار فاتورة المبيعات وصرف المخزون وترحيل تكلفة البضاعة المباعة لطلب متجر عند تسليمه. |
| إجراءات سريعة           | اختصارات في الشاشة الرئيسية لإنشاء المستندات الشائعة.                                 |
| أساس الاحتساب           | الربح الذي تُطبَّق عليه نسبة الشريك: مجمل الربح أو صافي الربح.                        |
| أمر الشراء              | اتفاق مع مورد على الشراء؛ لا يُدخل مخزونًا ولا يُنشئ قيدًا.                           |
| البحث المتقدم عن عميل   | أداة مقيّدة ومسجّلة للتأكد من وجود عميل في الشركة ولمن يتبع.                          |
| تحصيلات المتجر          | شاشة المالية لتأكيد أو رفض المدفوعات التي أبلغت عنها المبيعات أو شركات الشحن.         |
| تكلفة البضاعة المباعة   | تكلفة الأصناف المسلَّمة للعميل بمتوسط التكلفة وقت التسليم.                            |
| الجلسة                  | فترة دخولك للنظام؛ تنتهي بالخروج أو إغلاق المتصفح أو ساعتين دون نشاط أو 12 ساعة.      |
| الحجز                   | كمية محجوزة لطلب مشحون؛ تُنقص المتاح ولا تُنقص الرصيد الفعلي.                         |
| الرصيد الفعلي           | الكمية الموجودة فعلًا في المستودع.                                                    |
| الرصيد المستحق          | ما تبقى على العميل بعد خصم ما دفعه.                                                   |
| سند القبض               | مستند محاسبي لاستلام مبلغ من عميل.                                                    |
| السجلات المرتبطة        | لوحة تعرض كل المستندات والقيود والحركات الناتجة عن مستند.                             |
| الشريك                  | شريك في الشركة له نسبة أرباح حسب اتفاقية سارية.                                       |
| صافي الربح              | مجمل الربح ناقص المصروفات والبنود الأخرى.                                             |
| الصلاحيات الافتراضية    | صلاحيات المسمى الوظيفي التي يرثها كل من يحمله.                                        |
| طلب متجر                | طلب بيع لعميل نهائي يُشحن أو يُستلم، يدويًا أو مستوردًا من المتجر الإلكتروني.         |
| الطقم (المجموعة)        | منتج يُباع كبند واحد ويُجهَّز من مكوّنات؛ ليس له رصيد خاص.                            |
| العميل المتكرر          | عميل له طلبان أو أكثر غير ملغيين.                                                     |
| عميل محتمل (ليد)        | شخص مهتم لم يُنشأ له طلب بعد.                                                         |
| فشل الإثبات             | حالة طلب مُسلَّم تعذّر إصدار فاتورته أو صرف مخزونه، مع ذكر السبب.                     |
| فترة الأرباح            | شهر أو ربع أو سنة تُحسب عنها أنصبة الشركاء وتُقفل.                                    |
| القيد اليومي            | تسجيل محاسبي متوازن (مدين = دائن).                                                    |
| المتاح                  | الرصيد الفعلي ناقص المحجوز.                                                           |
| مجمل الربح              | صافي الإيرادات ناقص تكلفة المبيعات.                                                   |
| المحتجز للشركة          | ما يتبقى من الربح بعد أنصبة الشركاء.                                                  |
| مرتجع قيد المعالجة      | طلب أُرجع بعد تسليمه وينتظر تسجيل مرتجع المبيعات.                                     |
| مدفوع مقدمًا (للشريك)   | ما دُفع للشريك زيادة عن أنصبته المعتمدة.                                              |
| المسمى الوظيفي          | وصف الوظيفة، ويحمل الصلاحيات الافتراضية.                                              |
| منحة فردية              | صلاحية أُعطيت لمستخدم بعينه إضافة إلى صلاحيات مسماه.                                  |
| منع فردي                | صلاحية مُنعت عن مستخدم بعينه حتى لو ورثها؛ المنع يغلب دائمًا.                         |
| المعتمد (للشريك)        | أنصبة الشريك من الفترات المقفلة فقط.                                                  |
| التقديري                | رقم يُحسب الآن من القيود المرحّلة ويتغير حتى إقفال الفترة.                            |
| معاينة الأثر            | عرض ما يكتسبه ويفقده كل مستخدم قبل حفظ تغيير صلاحيات المسمى الوظيفي.                  |
| المنتج المجمّع          | منتج يُنتج بأمر تجميع وله رصيد خاص، ويُصرف هو نفسه عند البيع.                         |
| الوكيل                  | جهة خارجية تبيع بضاعتها عبر الشركة ولها بوابة خاصة.                                   |
| بضاعة الوكيل            | منتجات يملكها الوكيل ومخزّنة لدى الشركة، ولا تدخل قيمة مخزون الشركة.                  |
| رقم التتبع (رقم الشحنة) | رقم الطرد لدى شركة الشحن.                                                             |
