# الإعدادات الأساسية

صفحات **الإعدادات** مقسّمة حسب مجال العمل: عام، المالية، الشحن، التكاليف، علاقات العملاء، التكاملات. تظهر لكل مستخدم الصفحات التي يملك صلاحيتها فقط.

## خريطة الإعدادات

| المجموعة       | الصفحات المتاحة في R15                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| عام            | ترقيم المستندات، الأقسام، المسميات الوظيفية، المستخدمون                                                                 |
| المالية        | إعدادات الحسابات، دفاتر اليومية، طرق الدفع، شروط الدفع، العملات، الضرائب، السنوات والفترات المالية، إقفال السنة المالية |
| الشحن          | شركات الشحن، حالات الشحن، حالات سير العمل، قواعد الانتقال المتقدمة                                                      |
| التكاليف       | فئات التكلفة، قواعد تكلفة التجهيز، قواعد توزيع التكاليف                                                                 |
| علاقات العملاء | تصنيفات العملاء المحتملين، أسباب عدم الشراء، أنواع متابعة العملاء المحتملين                                             |

> [!note] صفحات قيد التطوير
> صفحات **بيانات الشركة** و**إعدادات الطباعة** و**الإشعارات** و**الأمان** و**النسخ الاحتياطي** و**التكاملات** تظهر في القائمة لكنها في هذا الإصدار صفحات «قريبًا» بلا إعدادات قابلة للتعديل.

## ترقيم المستندات

**أين تذهب:** **الإعدادات** ← **ترقيم المستندات**.
**الصلاحية:** إدارة الترقيم.

كل المستندات تُرقَّم تلقائيًا (طلبات المتجر `STO-2026-000001`، الفواتير `INV-2026-000001`، العملاء `PT-2026-000002`...). لا يحتاج المستخدم لكتابة أي رقم.

![ترقيم المستندات](11-01-numbering)

- [1] **القالب**: مثل `{DOC}-{YEAR}-{SEQ}`.
- [2] **معاينة الرقم التالي** قبل الحفظ.

> [!warn] تنبيه
> غيّر قالب الترقيم في بداية سنة مالية فقط وبعد التنسيق مع المحاسب، لأن الأرقام تُستخدم كمراجع في القيود والتقارير.

## شركات الشحن وحالات الشحن

**أين تذهب:** **الإعدادات** ← **شركات الشحن** / **حالات الشحن**.

![شركات الشحن](11-02-carriers)

- [1] زر الإضافة لتسجيل شركة شحن جديدة (الاسم والنوع والوصف).

- **طريقة تحصيل الدفع عند الاستلام** (في بيانات شركة الشحن): طريقة الدفع التي تُسجَّل عليها مبالغ الدفع عند الاستلام التي تحصّلها هذه الشركة، وتُطابَق مع كشوفها (الفصل 7). إذا لم تُحدَّد، يظهر في الطلب أن التحصيل غير مُتتبَّع لدى هذه الشركة.
- لا تُحذف شركة الشحن المستخدمة؛ تُؤرشف وتختفي من قوائم الاختيار.
- **حالات الشحن** الأساسية ثابتة (جاهز للشحن، تم الشحن، قيد التوصيل، تم التسليم، فشل التسليم...)، ويمكن إضافة حالات خاصة بألوان مميزة.

## إعدادات الحسابات

**أين تذهب:** **الإعدادات** ← **إعدادات الحسابات**.
**الصلاحية:** إعدادات المالية.

![إعدادات الحسابات](11-03-accounting-settings)

- [1] **العملة الرئيسية للنظام والقوائم المالية**: تُختار مرة واحدة هنا فقط، ولا يفترض النظام أي عملة بدلًا منها.

في نفس الصفحة تُحدَّد الحسابات التي تستخدمها القيود التلقائية: الصندوق والبنك، العملاء والموردون، المخزون وتكلفة المبيعات، الإيرادات والمرتجعات والخصومات، مصروفات الشحن والتجهيز، وحسابا **الشركاء** (الفصل 9). نقص حساب مطلوب يمنع ترحيل المستند المرتبط به برسالة توضح الحساب الناقص.

## البيانات الأساسية للمنتجات والمستودعات

من **المنتجات والمخازن**:

- **المنتجات**: الاسم (_)، الفئة (_)، وحدة القياس (*)، نوع الصنف (منتج / خدمة)، طريقة التوريد (شراء / تجميع / مجموعة)، الأسعار، و«تتبع المخزون». المنتج المخزني يحتاج الوزن والأبعاد. كود المنتج مثل `PRD-2026-000001` يُولَّد تلقائيًا.
- **المستودعات**، **مواقع المستودعات**، **وحدات القياس** وتحويلاتها، **الفئات**، **العلامات التجارية**.
- المنتجات لا تُحذف نهائيًا؛ تُؤرشف.

## البيانات الأساسية العامة

من **البيانات الأساسية**: الدول، المدن، اللغات، أنواع المعاملات. الدولة تحدد رمز الاتصال والعملة المقترحة للطلبات (مثلًا مصر ← الجنيه المصري، السعودية ← الريال السعودي، وباقي الدول ← الدولار الأمريكي).
